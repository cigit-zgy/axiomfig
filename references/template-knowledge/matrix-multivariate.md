# Matrix, ordination, and association routing

Use sequential heatmaps for ordered one-sided magnitude and diverging heatmaps only with an explicit
meaningful center. Correlation matrices use a signed scale centered at zero. Ordination templates
visualize precomputed coordinates and must state method-specific metadata such as explained
variance, distance metric, or stress. Mantel and correlation-network templates receive precomputed
relationships and significance; visualization does not perform the statistical test. Avoid dense
network spaghetti and rainbow maps for ordered values.
