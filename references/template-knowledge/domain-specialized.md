# Domain-specialized routing

Use Sankey for conserved flows between explicit source and target categories. Use contour for a
scalar field and quiver for a vector field; select sequential, diverging, or cyclic color semantics
from the scientific meaning. Volcano requires adjusted p-values and explicit thresholds;
enrichment dot plots map effect, significance, and count separately. Kaplan–Meier requires
precomputed survival probabilities and censoring. Do not imply uncomputed statistics or use pie
charts for precise multi-category comparison.
