# Security policy

Report sensitive vulnerabilities through the repository's private GitHub security-advisory channel.
Do not disclose credentials, private datasets, or exploitable details in a public issue. Public
issues are appropriate for non-sensitive correctness and rendering defects.

Only the current `master` line is supported before a tagged maintenance series exists. Reports
should include the AxiomFig version, Python version, operating system, minimal reproduction, and
whether untrusted Figure Intent or data was involved.
