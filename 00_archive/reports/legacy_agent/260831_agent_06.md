# AxiomFig Scientific Layout Engine Benchmark 报告

## 结论

**Verdict: PASS。** 本轮建立了隔离的 scientific-layout benchmark：10 种复杂统计图形分别生成
`original`、`default`、`kiwi`、`adjusttext`、`textalloc` 五列，共 50 个 PDF。所有 PDF 均为单页、

## Benchmark design

正式 benchmark surface 为：

```text
gallery/layout_benchmark/
├── SOURCES.md
├── original/    # 10 PDFs
├── default/     # 10 PDFs
├── kiwi/        # 10 PDFs
├── adjusttext/  # 10 PDFs
└── textalloc/   # 10 PDFs
```

不存在提交的 PNG、组合 backend 或额外 root 文件。`original` 只承担权威 topology/reference；四个实验列
共享冻结 visualization-ready fixtures、case-specific publication size、AxiomFig XCharter serif typography、
颜色、线宽、marker、tick 与 legend 合同。外部工具只能改变 layout/text coordinates。

每个实验 backend/case 重复生成 5 次。几何签名覆盖 Axes、文本 bbox、line/path、patch 与 annotation
connector，容差为 0.01 pt。指标由 Matplotlib renderer 在物理 point space 中测量；缺少适用 consumer 的
指标记录为 `null`，不伪装成零缺陷。

## Original reference generation

ID 01–08 由对应 first-party library/documented API 直接生成 PDF；其中 ID 01 的 matrix 是小型 rasterized
component，因此披露为 mixed vector/raster。ID 09/10 没有稳定、可复现的本地官方分析环境，故使用精确
first-party PNG 并通过 img2pdf 无损包装，不裁剪、不重采样、不宣称 vector reconstruction。最终 Type 3
审计发现早期 direct exports 使用 Matplotlib Type 3 fonts；生成器随后在 original-only neutral rc context
中固定 `pdf.fonttype=42`，不施加 AxiomFig style。8 张变更后的 vector originals 已逐张重新打开，布局不变。

## Default baseline

Default 使用同一 deterministic rectangle/grid grammar 和 renderer/bbox 文字位置，不调用 Kiwi、
adjustText 或 textalloc。10 个案例的 axes overlap、ornament overlap、clipping 和 minimum-gap violations
均为 0。文本密集的 ID 08/09 分别有 6/14 个 text-text overlap，以及 16/18 个被检查的 text-data
overlap；这些缺陷构成外部文字分配器的有效对照。

## Kiwi results

Kiwi 用一套共享 Cassowary constraint policy 解 width/height ratios、outer bounds、equal gaps 和 row/column
positions；无 case-specific constraints。10 个 PDF 与 default 的 PDF blob 完全相同，全部量化指标和视觉
几何相同。它证明约束表达能重现现有算术，但没有在本 benchmark 中改善 4 个案例或替换生产 bespoke
layout arithmetic，因此不满足 `ADOPT_CORE` gate。

## adjustText results

adjustText 仅作用于 ID 08/09 的 annotation text/connectors；axes、data artists、ornaments 与 scientific
reference 不变。一套公共 policy 消除了两例全部 text-text collisions，并把 text-data overlap 从 16/18
降至 7/8。代价是 label-anchor median displacement 从约 2.0 pt 增至 2.981/3.600 pt；ID 09 median
runtime 为 0.411 s，明显高于 default 的 0.042 s。几何在全部 5 次 run 中可重复。

## textalloc results

textalloc 同样只作用于 ID 08/09，并保留相同 labels/anchors。它消除了全部 text-text collision，并把
text-data overlap 降至 0/3，是本轮最佳碰撞结果；代价是 median displacement 达 5.635/7.162 pt，
大于 adjustText。ID 08/09 median runtime 为 0.045/0.048 s，接近 default。全部 5 次 run 可重复。

## Repeatability

Default、Kiwi、adjustText、textalloc 都是 `10/10` repeatable，5 次运行最大几何漂移均为 `0.000 pt`。
Random seeds、fixture arrays、model results、label identity/order 和 official raster checksum 均冻结。repeatability
signature 包含 connector/leader-line paths，避免「文本 bbox 不变但连线变化」的假阳性。

## Engineering complexity

生成/测量脚本共 1765 LOC，tests 315 LOC；这包括 10 个 fixtures/builders、10 个 original paths、
5-run measurement 和 provenance checks，不能全部归因于某个 backend。边际 backend 成本如下：

| Backend | Common-policy LOC | Case-specific numeric overrides | Runtime sum | Dependency | Integration complexity |
|---|---:|---:|---:|---|---|
| Kiwi | 约 49 | 0 | 0.636 s | Kiwisolver 1.5.0，Matplotlib 已传递提供 | medium；需维护 constraint representation，但本轮无收益 |
| adjustText | 约 23 | 0；仅限定 eligible IDs 08/09 | 1.087 s | adjustText 1.4.0，transient benchmark install | low/medium；API 小，但 ID 09 runtime 较高 |
| textalloc | 约 23 | 0；仅限定 eligible IDs 08/09 | 0.722 s | textalloc 1.2.4，transient benchmark install | medium；碰撞最好，但 displacement policy 需进一步约束 |

SciPy 1.17.1 支持冻结 linkage/dendrogram benchmark fixtures；`scipy>=1.16` 仅加入 `dev` extra 以使
CI 可导入并测试 benchmark generator。adjustText、textalloc、lifelines、img2pdf 未加入 production 或 dev
dependencies；Seaborn/statsmodels/sklearn/lifelines 只用于 transient original generation。

## Adoption recommendation

| Candidate | Classification | Evidence |
|---|---|---|
| Kiwi | `REFERENCE_ONLY` | 10/10 deterministic，但与 default 完全相同；未改善至少 4 个 layout-heavy cases，也未证明可替换生产 bespoke arithmetic。 |
| adjustText | `REFERENCE_ONLY` | 两个 eligible text cases 均改善且 deterministic，但只有 2 个，低于至少 3 个 text-heavy cases 的 gate；ID 09 runtime 明显较高。 |
| textalloc | `REFERENCE_ONLY` | 两个 eligible cases 碰撞最少且 deterministic，但只有 2 个，低于 gate；label displacement 显著增加。 |

本轮仅有两个科学上有效的 text-allocation stress cases。为了达到数量门槛而把 allocator 强行套到没有
可移动 scientific annotations 的图上，会污染 benchmark。因此本轮不能评估或声称 `ADOPT_CORE` /
`ADOPT_OPTIONAL`。三个候选都没有进入 AxiomFig runtime。

## Remaining work

1. 不集成任何 candidate。若未来仍需选择 annotation allocator，先单独设计至少一个第三类、科学上真实的
   text-heavy figure grammar，并冻结 anchor-preservation 与 displacement acceptance criteria。
2. 优先比较 textalloc 与 adjustText 的 label displacement、connector crossing 和 runtime，不重复评估已无
   收益的 Kiwi 1:1 geometry reproduction。
3. 若后续工具仍不能满足少量高价值 annotation case，优先保留 AxiomFig renderer/bbox-specific helper，
   不引入通用 layout engine。
