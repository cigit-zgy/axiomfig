## 3. 最终 anatomy 与模块职责

执行链保持 layer/composition 架构：

```plain
precomputed scientific data
  -> synchronized ordering
  -> MatrixGeometry + MatrixLabelLayer
  -> CorrelationGlyphLayer
  -> StatisticalOverlayLayer[]
  -> DiagonalInterface / TargetNode[]
  -> CouplingLayer / SourceNode[] / fan / lanes / Bezier paths
  -> OrnamentLayer
  -> AxiomFig runtime + artifact validation
```

| 模块 | 单一职责 |
|---|---|
| `composition.py` | frozen scientific composition、canonical/advanced semantics |
| `data.py` | precomputed matrix/link/statistical input validation |
| `geometry.py` | measured gutters、matrix/coupling triangles、node positions、ornament zone |
| `matrix.py` | structural cells、mask、subtle scaffold 与 matrix-side labels |
| `glyphs.py` | circle/square/ellipse/number/shade/color/pie reusable primitives |
| `overlays.py` | coefficient/significance/CI/cluster independent artists |
| `nodes.py` | SourceNode、TargetNode 与 source labels |
| `coupling.py` | node-to-node deterministic route candidates、fan/lane allocation 与 scoring |
| `legends.py` | measured Mantel p/r legends；Pearson colorbar 保持 Auxiliary Axes |
| `quality.py` | renderer-based occupancy、clearance、collision 与 route-separation metrics |
| `builder.py` | 两阶段 orchestration，不包含 finished-picture case branches |

Mantel 子包为 3148 LOC。增加的代码来自显式 responsibility split、geometry gates 与 metrics，
不是 21/49 套硬编码画法。`7 x 3` base 与 `7 x 7` mixed 继续通过同一 primitive composition
engine。

## 4. 矩阵、标签与 node contract

两种 canonical orientation 是严格互补关系：

| `matrix_region` | Matrix labels | Coupling triangle | Diagonal direction |
|---|---|---|---|
| `lower_left` | left + bottom | upper-right | lower-left -> upper-right |
| `upper_right` | top + right | lower-left | upper-left -> lower-right |

Label sides 由 matrix region 自动决定，不属于 LLM 可选坐标。变量名称只出现在有色矩阵相邻边；
对角接口不放 variable labels。每个 ordered variable 恰有一个小型 TargetNode，每个 source group
恰有一个更强的 SourceNode；所有 curves 的 path endpoints 精确对应这两类 node。

Canonical matrix glyph 改为 circle；circle radius 使用 `sqrt(abs(r))`，因此 glyph area 与
`abs(Pearson r)` 成正比。Square 及其他 6 种 glyph 继续完整支持，R-reference example 仍可明确
选择对应方法。Matrix scaffold 使用低对比 neutral stroke，避免 cell frame 与 glyph edge 同权。

## 5. Renderer-aware physical layout

Builder 先创建 Figure、Primary Axes 与 Auxiliary colorbar Axes，再取得真实 renderer。布局测量使用：

- `renderer.get_text_width_height_descent()`：row/column/source labels；
- `artist.get_window_extent()`：Mantel r/p legends；
- `Bbox`：artist containment、overlap、clearance 与 panel ownership；
- resolved Latin Modern Sans/Serif font properties、实际 DPI 与 point-to-pixel transform。

对多词 source label 只做一次 measured word-boundary wrap 候选比较；没有 `len(label)` 到 gutter
的字符宽度估算，也没有迭代 brute-force。最终 geometry 在固定 1-2 passes 内求解。长标签测试包括
`Dissolved oxygen`、`Ammonium nitrogen`、`Nitrate nitrogen`、`Total phosphorus`、
`Chemical oxygen demand` 与 `Redox potential`，annotation containment、label collision 和
panel validation 均为 0 failure。

两个独立 Mantel legends 位于 primary visual square 外的 measured ornament zone；Pearson
colorbar 是 panel-owned Auxiliary Axes。所有 bbox 在真实 draw 后复核，legend mutual overlap、
legend/matrix overlap 与 page overflow 均为 0。

## 6. Coupling routing

Source positions 由 coupling triangle、source count、text extents 与 target distribution 决定，
不是固定 3/4-source 坐标。每个 source 的 links 先按 target position 排序，再分配 fan angle 与
lane；候选 two-cubic Bezier control points 从 coupling triangle 的 tangent/normal basis、source order、
target order 与 lane index 推导。

候选路线依次惩罚 matrix/glyph intrusion、source-label collision、既有路线 crossing、near-parallel
proximity 与 excessive curvature。算法无随机数、force layout 或最终坐标表。Canonical、sparse、
dense 与 3/4-source 图中每条曲线都从可见 SourceNode 出发并结束于可见 TargetNode；默认
non-significant links 使用低 alpha AxiomGrey 作为结构背景。

## 7. Color 与 semantic defaults

所有色值来自 packaged `resources/styles/colors.yaml`，Mantel renderer 中 raw hex 与 `RdBu` 均为 0。

```plain
Pearson: -1 AxiomRed -> 0 AxiomWhite -> +1 AxiomBlue
Mantel p canonical:
  p < 0.01         AxiomOrange
  0.01 <= p < 0.05 AxiomGreen
  p >= 0.05        AxiomGrey, low alpha
Mantel p detailed:
  保留既有 Orange / Green / Purple / Grey 四档能力
Mantel r:
  abs(r) -> style-owned linewidth bins
```

Figure Intent 只增加/保留 `matrix_region`、`matrix_method`、ordering、statistical overlay 与
nonsignificant policy 等科学语义；source/target coordinates、control points、font size、line width、
legend coordinates 与 RGB 均未暴露。

## 12. 已知差异与剩余限制

- Coverage 是 corrplot/linkET/ggcor scientific grammar parity，不是 R theme、ggplot2 grid unit 或像素级复制；
  palette、typography、stroke、physical geometry 与 ornaments 服从 AxiomFig contract。
- Routing 是 deterministic two-cubic geometry，不复刻 linkET/ggcor 的 R plotting internals；在任意极端
  dense topology 中仍可能存在无法消除的 link-link crossing。
- 设计目标是 manuscript-scale 约 10-20 variables 与几十条 links；hundreds of variables 需要聚合或
  其他科学展示策略。
- AxiomFig 不计算 Pearson correlation、p-values、CI、clustering 或 Mantel statistics；输入必须为
  precomputed scientific result。
- 本轮不处理 CJK/Japanese canonical typography 或 TeX-native Matplotlib labels。
