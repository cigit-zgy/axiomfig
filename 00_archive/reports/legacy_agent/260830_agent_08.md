# AxiomFig Mantel Visualization Engine 实施报告

## 1. 结论

`association/mantel` 已从单一 hard-coded upper-square builder 替换为独立的 Matplotlib/NumPy
Mantel Visualization Engine。公开模板仍只有 `association/mantel`；内部现支持 7 种 correlation
glyph、full/upper/lower/mixed、5 类变量排序、9 个 hclust spelling、cluster rectangle、coefficient、
5 种 significance mode、3 种 CI 可视化，以及确定性的 linkET-style coupling。

任务基线为 `61c072096f992edc2f04d75656e26ac2f6da5769`。实现提交为
`78b232fe7cbf6cccc280d0c4c7218a58180233f5`，该 SHA 的 GitHub Actions Python 3.11/3.12
均通过。本报告由后续 report-only 提交收录；报告提交的精确 SHA 由提交后 remote 核验，避免在
报告自身中制造循环引用。既有 `v1.0.0` 仍指向
`8c70caba07fc020962676f9344893de756aa5cba`，未移动、覆盖、删除或重建。

## 4. 数据合同与科学语义

公开必需角色保持紧凑：

```yaml
required: [correlation_matrix, labels, links]
link_fields: [source, target, mantel_r, p_value]
```

每条 link 可额外保留 `label` 和 `metadata`。旧 `source_group`/`target_label` 仍可输入，但 adapter
明确归一化为 `source`/`target`。高级可选角色只在 `association/contract.yaml` 暴露高层 scientific
semantics；物理 line width、font size、cell padding、curve coordinates、legend coordinates 和 RGB
仍不是 Figure Intent 字段。详细低频文档位于 `references/mantel.md`，SKILL 只增加一条 advanced
route，不要求普通 Agent 读取。

Correlation matrix 支持对称 `NaN` pair，并用明确 missing glyph 表示，绝不转为 0。p-value matrix
和 lower/upper CI 必须与 correlation matrix 同形、对称且值域有效；CI 必须满足
`lower <= estimate <= upper`。

Mantel r 的输入范围由旧 `[0, 1]` 修正为 `[-1, 1]`。负 Mantel correlation 对当前 precomputed
contract 是有效值。Canonical link width 编码 effect magnitude `abs(r)`，而 signed r 保留在 artist
metadata；这样不会把正负号错误映射为负线宽，也不额外占用 P-value color channel。

## 7. Canonical fixture、Gallery 与视觉检查

Canonical fixture 已由旧 5-variable/2-source/5-link 数据替换为 10-variable/3-source/15-link：

```plain
variables:
  DO, NH4-N, NO3-N, TN, PO4-P, TP, COD, pH, Temperature, ORP

source groups:
  Water chemistry, Nutrient profile, Process state
```

Correlation matrix 由固定 latent loadings 与正对角 residual covariance 构造，因而对称、unit
diagonal 且 positive semidefinite。15 条 link 同时覆盖正负 Mantel r、3 个 `|r|` bins 和 4 个 P
bins。Canonical defaults 为 square/lower/diag hide/original/fade/curved。

只重建以下 4 个永久 artifact：

```plain

gallery/sans/association/mantel.png
gallery/serif/association/mantel.pdf
gallery/serif/association/mantel.png
```

Sans 与 serif 的最终人工检查确认：10-variable matrix 紧凑；source label 不裁切；target label 只
出现一次；coupling 不穿过可见 glyph；三类 source routes 可追踪；legend 不再横跨整条底边；
Pearson colorbar 属于 matrix；无 overflow、collision 或 clipping。两份 PDF 均为
140 × 105 mm，分别嵌入 subset Latin Modern Sans 和 XCharter，无 Type 3。全 Gallery 仍为 112 PDF
+ 112 PNG，validator 全部通过；未增加 orphan Mantel variant。

## 10. 与 R 的已知差异和剩余限制

- AxiomFig 复现 agreed capability/behavior surface，不追求 R default 的逐像素外观。glyph color、stroke、
  typography、legend 与物理尺寸遵循 AxiomFig contract。
- hclust 的 Lance-Williams recurrence 与 requested linkage 一致；等距 merge 的 leaf orientation 使用
  stable original-index tie rule，可能与 R 的任意合法 dendrogram orientation 不同。cluster membership
  不受影响。
- `ward.D2` 在更新前平方 dissimilarity；`ward` 按 corrplot legacy spelling 归一化为 `ward.D`。
- CI square/circle 使用 endpoint outline + estimate marker，保留 correlation interval meaning，但不是
  corrplot patch stack 的像素复制。Matplotlib hatch 与 R shade density 也可能不同。
- `nice_curvature` 复现分离曲线的设计目的，不复制 ggplot2 grid unit API。AxiomFig 使用确定性 gate、
  lane 和 cubic Path，不实现 force-directed layout。
- 本引擎只针对约 10–20 variables、dozens of links 的 manuscript-scale case；不以 hundreds of
  variables 为 v1.x 目标。
- AxiomFig 不计算 Pearson correlation、p value、CI、Mantel test、permutation 或 clustering statistics。

本轮没有剩余 Important defect，也没有修改 taxonomy、其他 public template、`v1.0.0` tag 或 GitHub
Release。
