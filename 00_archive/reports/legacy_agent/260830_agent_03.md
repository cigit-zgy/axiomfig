每个 family 只保留 `__init__.py`、`builders.py` 和 `contract.yaml`。`registry.py` 使用显式 import、普通 mapping 和 PyYAML；未引入 plugin framework、动态 import、metaclass、DSL、database 或通用 schema framework。`layouts/` 只调用 Round 05 的 `layout.py`、`ornaments.py` 与 `anatomy.py`，不作为科研图类型进入 public Gallery。

`index.yaml` 共 60 行、1860 bytes，只记录 version、family、variant、geometry 与 public/layout 分类。运行路径固定为：

```plain
index.yaml
    → family/contract.yaml
    → explicit BUILDERS mapping
    → deterministic runtime
    → anatomy/PDF validation
    → Gallery family/variant path
```

每个 `contract.yaml` 声明 required/optional data fields，并保留必须显式给出的科学语义。例如 interval template 要求 `uncertainty_type`，correlation heatmap 要求 `center`，Mantel 要求预先计算的 `correlation_matrix`、`mantel_links` 和 `significance`。Contract 不包含科研问题推荐知识。当前 builder 保留确定性 canonical example data；通用外部数据适配层不在本轮范围内。

## 5. Panel label 根因与新规则

Round 05 的 lifecycle 与 ownership 已稳定，但 label 锚定 Outer Panel Footprint。实测 footprint 到 Primary Axes frame 的 inset 为：普通 panel 水平约 `30.84 pt`，heatmap/colorbar panel 水平约 `44.96 pt`，垂直约 `11.63 pt`。因此旧 apparent gap 主要来自 footprint 与 frame 的语义差异，不是 `2 pt` translation 本身；旧 label bbox 到 frame 的可见分离约为水平 `14.84–32.20 pt`、垂直 `13.63 pt`。

新规则为：

```plain
Outer Panel Footprint
├── reserved label gutter
└── Primary Axes frame
    └── label semantic anchor = frame upper-left + (-1 pt, +1 pt)
```

布局求解在 footprint 内按实际 11 pt bold label 高度预留 gutter。Label 放置后不参与或改变 Primary Axes 几何。Legend 仍独立测量 `N..1` column candidate；colorbar 仍是所属 footprint 内的 Auxiliary Axes，并按最终 `9 pt` 宽度测量 overhang。

最终几何测量：

| Typography | Layout | x gap | y gap |
|---|---|---:|---:|
| sans | 2×2 / 2×3 / 3×2 | `-1.000 pt` | `+1.000 pt` |
| serif | 2×2 / 2×3 / 3×2 | `-1.000 pt` | `+1.000 pt` |

中央 translation token 准确缩短为原值的 `0.5×`。由于同时修正了 semantic anchor，最终 bbox-to-frame gap 不再包含 footprint inset，因此实际视觉距离从十余 point 收敛为 1 point，而不是把旧复合距离机械缩放为一半。视觉审查确认 label 紧邻 frame 左上角，没有居中、legend collision、y tick/y label collision 或跨 panel 越界。

## 6. Mantel 与 color semantics

Mantel 现在是 `association/mantel` 的 first-class template，使用 140 × 105 mm onehalf-column geometry。Contract 声明相关矩阵、Mantel links、关系强度和显著性输入；canonical builder 当前使用确定性预计算 example data，绘图层不计算 Mantel test。

图形以紧凑 correlation matrix 与稀疏关系 links 表达结构。线宽编码 Mantel strength，实线/点线编码 significance，compact legend 解释两类语义；未增加第三方网络绘图库，也未使用装饰性 force-directed layout。Sans 与 serif PDF/PNG 均通过 runtime anatomy 和 PDF boundary gate。

Heatmap/field 的颜色语义继续来自中央 style/color contract。Sequential template 使用 `cividis`，correlation template 使用 `RdBu_r` 与显式 `TwoSlopeNorm(center=0)`；template 未写入 palette 数值或临时 colormap 决策。

## 8. 视觉审查与唯一修复

一次视觉审查覆盖 sans 的 line、scatter、bar、violin、correlation heatmap、forest、residual、Mantel、contour，serif 的 line、bar、correlation heatmap、Mantel、contour，以及 2×2、2×3、3×2 layout。人工检查了 stroke、tick direction/length、categorical axis、scatter alpha/size、bar label、panel label、legend、subplot symmetry、heatmap colorbar 和 sans/serif 一致性。

审查发现 1 个 Important：初版 `field/contour` 的数据域为 `[-2.5, 2.5]`，而 nice axis 显示域为 `[-3, 3]`，造成两侧白带。唯一 repair pass 将确定性 field 数据域与可见轴域统一为 `[-3, 3]`，新增 geometry test，随后完整重建 Gallery。最终复核没有剩余 Important。

Mantel serif 初始边界探测曾发现右侧 `Community` label 超界 `5.21 px`；这是 Gallery migration 期间的 deterministic boundary failure，修正 node x 后重建通过。未开启 reviewer/fixer 递归循环。
