# AxiomFig Round 03 视觉合同迭代与 Gallery 扩展报告

## 1. 结论

Round 03 已完成视觉合同迭代、20 × 2 Gallery 扩展、Charter-compatible serif 模式、开放字体内置与许可证归档、五套 canonical palette、LaTeX infrastructure 和 Tectonic finalization 核验。最终完整测试、静态检查、40 对 PDF/PNG 验证、字体检查、Skill 校验和人工视觉检查均通过。

本轮保持三个 YAML 唯一配置源、四个模板图族模块和薄 Python runtime，没有恢复 `.mplstyle`、大型配置框架、跨版本矩阵或组合式视觉搜索。

## 2. 本轮视觉规则修改

`styles/style.yaml` 继续集中管理 geometry、物理字号、stroke、ticks、legend、panel、layout、output 和 plot defaults。本轮新增或调整的中央 token 包括：

- legend top gap 为 `0.7 pt`，handle length 为 `1.0`；
- panel label 为 `(a)–(d)`、`10 pt` bold、左移 `2 pt`、上移 `2 pt`；
- output 默认 `tight`，物理 padding 为 `1.5 pt`，允许 `tight`、`normal`、`custom`；
- scatter 为 `36 pt²`、alpha `0.55`、黑色 `0.6 pt` edge；
- line/errorbar marker 为 `5.2 pt`，errorbar cap 为 `2.5 pt`；
- confidence interval、boxplot、violin、histogram 的 alpha、宽度和 edge 均由 YAML token 管理；
- `main_stroke = 0.8 pt` 与 `fill_edge = 0.6 pt` 保持不变。

模板不再分别硬编码 marker size、CI alpha/edge、box/violin alpha/edge 或 histogram edge。Python helper 只把明确的 YAML token 应用到 Matplotlib artists，没有引入通用配置抽象。

## 3. Colorbar、tick、legend、panel label 与 margin

`20_multi_panel` 保持严格 2 × 2 普通 axes grid。Heatmap colorbar 使用锚定 panel (d) 的独立 support `cax`，其高度等于 panel (d)，不改变四个主 axes box；panel (b) 与 panel (d) 左边界一致。Colorbar major/minor ticks 均向外。

Bar 和 violin 的数值轴改用 open-axis policy：major `inout`、minor `in`；categorical labels 保留且 tick marks 为零。只有 heatmap/image 这类覆盖 axes surface 的图使用 major/minor `out`。

Multi-series legend 紧贴 top spine、右边与 right spine 对齐、默认单行，仅测得 overflow 时减少列数；single-series 不生成 legend。Panel labels 以各自 axes 左上角为锚点和固定 point offset，不受 legend 或 colorbar 漂移影响。集中式 fixed-page solver 测量全部可见 artists，在不改变 90/140/190 mm 页面尺寸的前提下实现默认 `1.5 pt` padding。

20 个 public templates 收敛在 `curves.py`、`distributions.py`、`surfaces.py` 和 `panels.py` 四个图族模块。新增 `references/template-contract.md`，逐一映射 Gallery stem、builder、module 和 scientific intent。README 与 SKILL 已删除旧六模板描述，并把完成门槛更新为 sans/serif 各 20 个 PDF/PNG pair。

## 5. Serif、sans 与字体许可证

当前完整模式为：

| 模式 | Latin text | Math | Mono |
|---|---|---|---|
| `sans` | Latin Modern Sans | Latin Modern Math | Maple Mono |
| `serif` | XCharter | XCharter Math | Maple Mono |

上述开放字体文件已内置在 `fonts/`，许可证与 attribution 存放在 `fonts/licenses/`，并由 `styles/fonts.yaml` 的 `attribution_file` 与 `license_file` 精确关联。Latin Modern 使用 GUST Font License；[XCharter](https://www.ctan.org/tex-archive/fonts/xcharter) 保留 Bitstream Charter free-font notice；[XCharter Math](https://ctan.org/tex-archive/fonts/xcharter-math) 与 Maple Mono 使用完整 SIL Open Font License 1.1 文本。

Arial 和 Times New Roman 根据 [Microsoft font redistribution FAQ](https://learn.microsoft.com/en-us/typography/fonts/font-faq) 继续作为 `bundled: false`、`source: system`、`proprietary: true` 的 optional system fonts，不复制到公开仓库。SimSun 与 Yu Gothic 同样只保留 metadata，不构成已验证的 CJK typography path。

## 6. Palette 与 xcolor

`styles/colors.yaml` 是唯一颜色源，现包含 `tol_bright`、`tol_muted`、`axiom_classic`、`axiom_soft` 和 `grayscale`。Tol palettes 使用 [Paul Tol 官方 scientific colour schemes](https://sronpersonalpages.nl/~pault/) 的公开值；两套 `axiom_*` palette 为项目自有稳定 token，默认使用克制的 `axiom_classic`。

`scripts/generate_colors.py` 从默认 palette 确定性生成 `axiomfig-colors.tex`；Matplotlib 与 xcolor 不维护两套手工 RGB/HEX。

## 7. LaTeX 与 Tectonic 当前真实状态

根目录 `latex/` 现包含 `axiomfig.sty`、`axiomfig-colors.tex` 和 `README.md`。通用 package 组织 `xcolor`、`siunitx`、`mhchem`、`amsmath` 和 `unicode-math`，采用 XCharter text 与 XCharter Math，不包含 COD、BOD、ASM 或 ADM 等领域宏。`references/latex-contract.md` 明确 unit、chemistry、math 和 color 的准确语法。

实际 pipeline 为：

```plain
Matplotlib vector intermediate PDF
→ standalone includegraphics wrapper
→ Tectonic finalization
→ final PDF
→ Poppler PNG
```

`scripts/check_latex.py` 的真实 probe 成功生成 PDF、提取单位/化学/数学文本，并确认嵌入 XCharter Roman 与 XCharter Math。Tectonic 并不排版 Matplotlib 已嵌入的 figure text，因此不能声称 plot labels 原生支持 `\qty`、`\ce` 等宏。

## 11. Remaining limitations

Chinese/Japanese font expansion、CJK segmentation/rendering stress tests 与对应 Gallery 仍为 deferred。Arial、Times New Roman、SimSun、Yu Gothic 只是未内置的 optional system metadata，不是 canonical mode。

TeX-native Matplotlib typography 仍未实现：Tectonic 负责最终 PDF container，不会重新排版 Matplotlib 已嵌入文本。PGF 或原生 Tectonic label pipeline、跨 Python 版本兼容矩阵和重型 wheel matrix 均不属于本轮范围。

Poppler `pdffonts` 对 Matplotlib-origin PDF 会输出非致命的 font-type/file mismatch warning；实际 rows 仍显示 CID OpenType、embedded、subset 和 Unicode，Gallery validator、文本提取与视觉检查均通过。本轮未把该第三方诊断 warning 误报为字体缺失。
