# AxiomFig Mantel 关联模板重构报告

## 1. 结论

`association/mantel` 已从“相关热图 + 独立节点网络”的双面板拼接，重构为一个受确定性 panel
footprint 管理的正式 scientific grammar：上三角 Pearson 矩阵是主结构，左侧来源组与曲线是辅助
层，Mantel r 与 P value 图例独立置于底部，Pearson 色标固定在矩阵右侧。重构没有新增模板、
family 或统计计算能力；AxiomFig 仍只消费外部预计算的 Mantel 结果。

任务基线为 `8c70caba07fc020962676f9344893de756aa5cba`，开始时 local `master`、
`origin/master` 与 GitHub `master` 一致且工作树干净。本报告属于最终 Mantel 重构提交；其精确
SHA 由提交后 Git 与 GitHub remote 核验，避免在报告自身中制造循环引用。

## 2. 旧实现问题与新语义

旧 builder 创建 1×2 外层 panel：左侧完整 annotated heatmap，右侧再绘制任意 node network。
矩阵变量、network node 与 link label 没有共同坐标语义，边上重复标注 `r=...`，significance
只用二元 linestyle 表达；结果是矩阵、节点、连线和 legend 相互竞争，且 source 与 target 的
科学角色不明确。

新语义固定为：

```plain
precomputed Pearson matrix
  -> one upper triangle
  -> color = signed Pearson r
  -> square side = abs(Pearson r)

precomputed Mantel link
  -> source_group -> matrix target_label
  -> width bin = Mantel r
  -> color bin = P value
  -> p >= 0.05 hidden by default, optional faint-grey display
```

每个 artist 均位于同一注册 panel 内。矩阵、source node、target anchor、link、双 legend 与手工
vertical colorbar 使用固定互不重叠区域；link 使用 clipped cubic path，并保存 source/target、
Mantel r 与 P value 追踪属性。没有放宽 runtime validation。

## 3. Contract 与 adapter

公开 precomputed-result contract 由五个平行数组收敛为三个科学角色：

```yaml
required: [correlation_matrix, labels, links]
optional: [show_nonsignificant]
link_fields: [source_group, target_label, mantel_r, p_value]
```

Adapter 现在验证：

- correlation matrix 为有限、方形、对称、对角线等于 1，且值域为 [-1, 1]；
- labels 非空、唯一并与矩阵维度一致；
- links 为非空 mapping sequence，四个字段完整且不含未声明字段；
- target_label 必须属于 matrix labels；
- Mantel r 位于 [0, 1]，P value 位于 [0, 1]；
- source_group/target_label pair 不重复；
- `show_nonsignificant` 必须为 boolean。

Adapter 输出 tuple-of-mapping canonical representation，不再让 builder 临时解释
`matrix_labels`、`link_strength`、`significance` 与 `node_labels` 的位置关系。README 与 Figure
Intent reference 已同步新输入形式。

## 4. Visual tokens 与 builder

`style.yaml` 新增 Mantel 专属 token：upper triangle、cell-side range 0.18–0.86、dark cell
edge、canonical grey grid、diverging colormap、r breaks 0.25/0.50、P breaks
0.001/0.01/0.05、三档线宽、显著/非显著 alpha，以及 matrix/source/target/colorbar/legend
区域坐标。`config.py` 校验 cell、break、width、color-bin 与 boolean schema；`style.py` 负责
palette token 解析、Mantel r stroke mapping 与 P-value style mapping。

Canonical builder 使用 5×5 对称 Pearson 矩阵、2 个 source group 和 5 条 links。默认隐藏 2 条
非显著 links；P legend 仍显示非显著类别，确保视觉语义完整。Matrix 只绘制 15 个上三角
colored square，所有 square 保持相同 grid 对齐，边长连续编码 |r|，色彩使用以 0 为中心的
`RdBu_r`。

## 7. 范围与剩余限制

本轮没有改变 taxonomy、其他 template、全局 palette、字体、ticks、layout kernel、tag 或已发布
的 v1.0.0 Release。Mantel 仍不计算 Pearson correlation 或 Mantel statistics。

当前 canonical grammar 针对 small、medium 与 moderately dense manuscript cases 验证；默认隐藏
非显著边以控制 visual density。超过当前 6-variable/9-link dense fixture 很多的网络仍应由用户
先进行科学筛选，而不是依靠模板自动隐藏重要关系。Mantel r 的视觉 contract 按 [0, 1] effect
strength 定义；若未来需要公开表达 signed Mantel r，应作为显式语义扩展设计，不能把 sign 暗中
塞入现有 width-only encoding。当前没有剩余 Important defect。
