# AxiomFig Mantel 可组合可视化语法与视觉一致性报告

## 1. 结论

`association/mantel` 已从 option-driven finished-picture engine 重构为可组合的科学可视化语法。
矩阵结构、7 种 correlation glyph、统计 overlay、Mantel coupling 与 ornament 现在是独立层；
`7 × 3` base 与 `7 × 7` mixed 仍保持完整覆盖，但实现中不存在 21 或 49 套分支。

任务基线为 `6f78b778f269fa17614dc6033bacaa04ef9d69fe`，最终实现提交为
`401d813a8874f332d9c49941e1663a2854934dff`。该提交的 GitHub Actions Python 3.11/3.12
均通过。本报告由后续 report-only 提交收录，不改变实现、Gallery 或验证结论。既有
`v1.0.0` tag 未移动、覆盖、删除或重建，本轮未创建新 tag 或 Release。

## 2. 架构审计与重构结果

重构前，`MantelOptions` 聚合所有开关，`matrix.py` 同时处理 mask、glyph、mixed、significance、
CI 与 cluster，`coupling.py` 使用 source-column 与 top/bottom gate 的 two-stage route。该结构具备
能力覆盖，但 artist anatomy、科学语义与布局约束相互耦合，无法证明 mixed 与 overlay 真正可组合。

重构后的执行链为：

```plain
normalized data
  -> MantelComposition
  -> one synchronized ordering transformation
  -> MatrixLayer
  -> GlyphLayer[]
  -> StatisticalLayer[]
  -> CouplingLayer
  -> OrnamentLayer
  -> AxiomFig runtime validation
```

| 模块 | 职责 |
|---|---|
| `composition.py` | frozen composition model、科学语义归一化与默认值 |
| `data.py` | precomputed data validation，不负责 artist 或统计计算 |
| `geometry.py` | matrix bounds、TargetRail、source region 与 orientation-aware ornament constraints |
| `matrix.py` | 结构 mask、grid、labels 与 target anchors，不决定 glyph |
| `glyphs.py` | 7 个 reusable cell-local vector primitives |
| `overlays.py` | coefficient、significance、CI 与 cluster outline 独立 artists |
| `ordering.py` | original/alphabet/AOE/FPC/hclust 的唯一同步变换 |
| `coupling.py` | source-to-rail deterministic cubic routes |
| `legends.py` | matrix-owned Pearson colorbar 与 Mantel legends |
| `builder.py` | 按层编排，不包含 finished-picture case branches |

专用 Mantel 子包当前共 2327 LOC。新增 LOC 来自明确拆层、permanent parity manifest/atlas 与
geometry tests，不是 21/49 套绘图代码。

## 3. Rougier 原则的实现后果

本轮应用的是 Nicolas P. Rougier *Scientific Visualization: Python + Matplotlib* 的 anatomy、
layout、ornament、defaults、colors、typography 与 rules 原则，而不是复制书中图像或文字。

1. Figure 继续由 AxiomFig 决定物理页面；Mantel 只定义科学图形语法。
2. MatrixLayer 建立唯一 cell coordinate system 与 TargetRail，所有 artists 共享该几何。
3. Glyph 与 StatisticalLayer 只编码科学量，不拥有矩阵 mask 或 variable ordering。
4. CouplingLayer 只拥有 source、target、Mantel r 与 p 的关系编码。
5. OrnamentLayer 解释 artists，但不反向改变 matrix geometry。
6. 字体、字号、palette、stroke、cell side、curve clearance 与 legend 坐标继续来自 deterministic
   runtime/style contract，不进入 Figure Intent。

普通 Agent 路由未扩张：`SKILL.md -> registry -> association/contract.yaml` 足以生成 canonical
Mantel；只有高级组合请求才读取 `references/mantel.md`。

## 4. Composition primitives

`MantelComposition` 由 `MatrixSpec`、一个或多个 `GlyphSpec`、零个或多个 StatisticalOverlay 与
可选 `CouplingSpec` 构成。公开 Figure Intent 仍使用既有 flat semantics，内部才归一化为 frozen
dataclasses，没有新增 DSL、plugin framework、metaclass 或 arbitrary artist commands。

Mixed mode 的实现是：

```plain
lower structural mask -> GlyphLayer A
upper structural mask -> GlyphLayer B
```

因此 49 个 lower/upper glyph pair 通过同一组合路径。`CoefficientOverlay`、
`SignificanceOverlay`、`ConfidenceIntervalOverlay` 与 `ClusterOutlineOverlay` 均为独立 layer；
significance `blank` 只在统一 visibility policy 中影响 glyph，其余 significance mode 只生成
overlay artists。CI 使用 precomputed lower/estimate/upper，并可与 glyph 同 cell 共存。

Ordering 在任何 artist 生成前一次性同步变换 matrix、labels、p-values、CI、cluster membership
与 Mantel target mapping。没有渲染层自行重排数据。

## 5. Mantel geometry 与 routing

旧 source-column + gate routing 已完全删除。三角矩阵现在拥有显式 `TargetRail`：

| Orientation | Source region | Target progression |
|---|---|---|
| lower | lower-left | lower-left -> upper-right |
| upper | upper-left | upper-left -> lower-right |

每个变量只有一个由 index、cell geometry 与 central rail offset 推导的 anchor，matrix label 本身
就是 target identifier，不存在 detached target-label column。每条 link 是一个 rail-normal cubic，
control points 只由 source order、target order、link density、orientation 与 lane index确定。

新增 geometry gate 验证：

- lower/upper rail 严格单调且互为镜像；
- curve endpoint 精确等于对应 rail anchor；
- lower/upper route 的采样点不进入任何 visible glyph interior；
- source labels 互不碰撞，且不与两个 Mantel legends 碰撞；
- matrix cells、variable labels、legends 与 colorbar 保持 panel containment；
- full/mixed 的旋转变量标签 gutter 随最长 label 确定性增长。

首次 atlas review 暴露 source labels 与 legends 共享左下角的问题；修复后 lower ornaments 使用空闲
右下区域，upper ornaments 镜像到空闲右上区域。没有放宽 validation，也没有调整 matrix/glyph
视觉合同。

## 6. AxiomFig color contract

Mantel 已移除 Matplotlib `RdBu_r`。`colors.yaml` 现在声明 `axiom_diverging` constructed colormap：

```plain
-1                    0                    +1
AxiomRed          AxiomWhite           AxiomBlue
```

Pearson 三个 control tokens 分别来自 `axiom_classic` 与新增 neutral palette；生成的
`axiomfig-colors.tex` 同步包含 neutral xcolor tokens。Mantel p-value 使用：

| P-value | Axiom token |
|---|---|
| `< 0.001` | `AxiomOrange` |
| `0.001-0.01` | `AxiomGreen` |
| `0.01-0.05` | `AxiomPurple` |
| `>= 0.05` | `AxiomGrey` |

Mantel `abs(r)` 继续映射到 weak/moderate/strong line-width tokens，signed r 保留在 artist metadata。
源码测试确认 Mantel engine 内 `RdBu` 与 raw hex color literal 均为 0；颜色只从中央 style/color
contract 解析。

## 11. 与 R 的已知差异和剩余限制

- Parity 表示 agreed scientific grammar/capability coverage，不是 R default 的逐像素克隆。palette、
  stroke、typography、physical page 与 ornaments 遵循 AxiomFig contract。
- AOE/FPC/hclust 的科学排序能力保留；等距 hclust merge 使用 stable original-index tie rule，leaf
  orientation 可能与 R 的另一合法 orientation 不同。
- CI square/circle/rect 是 AxiomFig vector interval grammar，不复制 corrplot patch stack 的像素细节。
- Coupling 使用 deterministic rail-normal cubic，不复制 ggplot2 grid-unit API 或 force layout。
- 目标仍是约 10-20 variables、dozens of links 的 manuscript-scale figure；hundreds of variables
  需要其他展示策略。
- AxiomFig 不计算 Pearson correlation、p-value、CI、Mantel test、permutation 或 clustering
  statistics；这些输入必须预先计算。
- CJK/Japanese canonical typography 与 TeX-native Matplotlib labels 仍是既有 v1.x limitation，
  本轮未扩大范围。

本轮没有剩余 Important defect，没有新增 public template，也没有修改 taxonomy、其他 54 个模板、
`v1.0.0` tag 或 GitHub Release。
