## 2. 根因与修复

旧 `add_panel_axes(..., colorbar=True)` 先创建固定比例 `subgridspec(0.90, 0.02, 0.08)`，随后全局
solver 又手动重排同一组 axes。测量阶段把 9 pt Colorbar 临时拉到整个 footprint 高度，并把其上、下
tick/label overhang 错算为 Primary Axes 的 bottom/top inset。Canonical Mantel 的 Primary Axes allocation
因此从无此错误时可用的 `291.635 pt` 高度降为 `284.795 pt`，损失 `6.840 pt`；科学方形由此被无关的
Colorbar 垂直空白压缩。

最终实现删除固定比例 subgrid 和未使用的 `colorbar_width_ratio` / `colorbar_wspace`。Outer Panel
Footprint 直接拥有重叠的 Primary/Auxiliary Axes，唯一 solver 按以下顺序工作：

1. 测量 Primary Axes intrinsic decorations；
2. 以最终 `9 pt` 宽、`0.72` 高度的紧凑 Colorbar 探针测量右侧 tick/label overhang；
3. 只保留 right Ornament Strip；
4. 最大化剩余 Primary Visual Area；
5. 允许一次有界 renderer correction，处理紧凑 Colorbar 改变自动 tick text 的情况；
6. 对注册的 square scientific area 计算 maximum-feasible area 与效率。

`LayoutConstraintError` 现在会在物理尺寸不可行时说明 Primary Visual Area 或 measured right Colorbar
strip 无法容纳，而不是静默缩字体、缩 Colorbar、扭曲 square 或产生 overlap。

## 4. Colorbar 合同

全局 vertical Colorbar 合同仍由 `src/axiomfig/resources/styles/style.yaml` 单独拥有：

```plain
width:             9.000 pt
gap:               6.000 pt
length fraction:   0.720000
alignment:         center
tick side:         right
label side:        right
```

Canonical Pearson Colorbar 实测长度 `152.570 pt`，与 `211.902 pt` Primary Visual Area 的比例为
`0.720000`，vertical center error 为 `0.000 pt`。Mantel 仍只提供 Pearson scalar mapping、ticks 和
`Pearson r` label；通用尺寸、位置与 reservation 不在 Mantel 或 Figure Intent 中。

当前所有生产 vertical Colorbar 消费者均经过同一 renderer 测试：

- Field：`contour`、`quiver`；

审计发现 `omics/enrichment_dot` 的长 Colorbar label 在初始紧凑探针与最终 tick selection 间产生
`4.005 pt` overhang 差异。一次有界 renderer correction 重新测量并调整 right strip 后，所有消费者的
decorated Colorbar bbox 均处于其 Outer Panel Footprint 内。

附加人工检查对象 `gallery/sans/heatmap/correlation.png` 的主轴为
`154.505 x 159.987 pt`，Colorbar 为 `9.000 x 115.191 pt`，gap `6.000 pt`、height fraction
`0.720000`、center error `0.000 pt`。该模板不声明 square primary，因此保持数据主轴的既定矩形语义。
Horizontal Colorbar 仍未标准化，因为当前没有生产消费者。

## 8. 文档与剩余限制

- `references/layout-contract.md` 正式定义 Primary Visual Area、四侧 Ornament Strip、最大可行面积、
  vertical Colorbar ownership、物理单位与显式失败行为；
- `references/style-contract.md` 规定 right strip 的 width/gap/real-overhang/padding 核算；
- `references/mantel.md` 只引用全局合同，不重复物理 Colorbar spec；
- Figure Intent 仍不暴露任何 Colorbar、legend 或 axes 物理坐标。

剩余限制只有明确的既有范围：horizontal Colorbar 尚无全局合同；非注册 square 的普通模板不计算 square
efficiency；物理页面确实不足时直接报错，不自动缩小字体、marker 或科学语义内容。
