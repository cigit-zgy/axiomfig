## Architecture verdict

Architecture remains frozen and coherent:

- `SKILL.md` is unchanged and remains the short router.
- `references/template-knowledge/` owns scientific choice, clarification, misuse, unit, causality,
  and upstream-analysis guidance.
- Figure Intent remains the sole LLM/runtime boundary; no second schema or generic option bag was
  added.
- `templates/index.yaml` remains discovery-only.
- family `contract.yaml` and `adapter.py` own typed scientific inputs and validation.
- builders own invariant plot grammar; visual style/layout remains deterministic and prompt-hidden.
- no `src/axiomfig/agent`, provider SDK, analysis package, dynamic plugin system, or hidden PCA,
  clustering, Mantel, regression, survival, ROC, PR, or inferential computation was introduced.

## Scientific knowledge

Before this round, the five routed topics contained only 40 short prose lines and did not provide
template-level scientific decision boundaries. After the audit they contain 5,234 words total,
approximately 1,000 words per topic, while remaining progressively disclosed:

| Topic | Templates covered | Main additions |
|---|---:|---|
| `trend-comparison.md` | 13 | ordered trajectory, continuity, step/area baseline, bar versus distribution, stacked versus normalized composition |
| `distribution-relationship.md` | 14 | histogram/density/ECDF, raw-point visibility, parity versus relationship/agreement, bubble area and dense scatter |
| `uncertainty-model.md` | 11 | SD/SE/CI/PI/credible interval, reference/null semantics, Bland-Altman, ROC/PR/calibration, feature-importance meaning |
| `matrix-multivariate.md` | 11 | sequential/diverging matrix semantics, precomputed clustering, PCA/PCoA/NMDS, Mantel and association limits |
| `domain-specialized.md` | 6 | Sankey, scalar/vector fields, volcano/enrichment result meaning, precomputed survival |

The durable rules are operational rather than aesthetic: why one registered template is appropriate,
why a nearby alternative is not, what must be supplied, what cannot be inferred, and when upstream
analysis or clarification is required. Nontrivial rules were checked against the cited
error-bar/distribution literature, Bland-Altman agreement guidance, ROC/PR literature, and official
PCA/PCoA/NMDS method documentation already linked from the routed topics.

## Scientific ownership audit

| Scientific concept | Previous owner/problem | Final owner | Status / evidence | Remaining gap |
|---|---|---|---|---|
| Uncertainty type | thin Agent guidance | knowledge + typed family roles | SD, SE, CI, PI and credible intervals are non-interchangeable; unknown type routes to clarification | no generic uncertainty ontology planned |
| Distribution representation | ambiguous summary routing | knowledge | raw observations, summaries, histograms, ECDF and supplied density separated | qualitative sample-size guidance only |
| Reference/null values | external forest/coefficient invented defaults | optional typed semantics + builder | supplied reference is rendered; absent reference is omitted | ratio-scale display remains template-specific |
| Scale/transformation | transform conventions were implicit | knowledge + family role metadata | display transforms separated from analysis; volcano roles now explicitly mean log2 FC and adjusted p | no general scale engine |
| Precomputed analysis boundary | partial | contracts + knowledge + protocol | clustering, ordination, Mantel, diagnostics, omics and survival explicitly remain upstream | none for current surface |
| Bland-Altman agreement | external builder computed bias/limits | upstream analysis + optional all-or-none contract group | base mean-difference input remains compatible; supplied agreement references render; no hidden computation | none for current contract |
| Diverging center | accepted semantic was not executable in generic heatmap/contour | family contract + adapter + builder | explicit center required only for diverging semantics; renderer consumes it | no automatic center inference |
| Classification diagnostics | PR baseline and y-domain were unsafe | optional semantic + invariant probability domain | absent prevalence baseline is omitted; 0–1 precision remains visible | ROC versus PR choice remains study-dependent |
| Ordination | methods easily conflated | precomputed contracts + knowledge | PCA, PCoA and NMDS inputs/interpretations separated | no ordination computation |
| Correlation/association | causal overstatement risk | knowledge + protocol | association is not promoted to causality | study design cannot be inferred by runtime |
| Feature importance | definition could be treated as universal | required family semantic + knowledge | importance type remains explicit | no cross-method normalization |
| Omics | generic field names hid transforms | family `role_semantics` + knowledge | volcano effect is log2 FC; significance roles are adjusted p-values | enrichment dot `size` meaning remains dataset-specific |
| Survival | raw-event request could invite fitting | precomputed contract + knowledge | curve, CI and censoring remain supplied results | no KM fitting, HR, or log-rank analysis |
| Units | no runtime unit model | Agent scientific gate | parity/shared comparisons require compatible quantities and explicit conversion | no Pint/UCUM framework by design |
| Causality | dispersed warnings | protocol + routed knowledge | correlation, Mantel, networks, regression and importance do not establish causation | upstream study design remains authoritative |

Classification summary:

- **S0: 3 found / 3 fixed** — arbitrary forest reference, hidden Bland-Altman agreement computation,
  and PR probability-domain clipping.
- **S1: 6 found / 6 fixed** — coefficient reference, PR prevalence baseline, generic heatmap center,
  contour center, volcano role semantics, enrichment significance semantics.
- **S2: 7 found** — three cross-cutting guidance gaps were closed (analysis/display, units,
  causality); four scoped gaps remain deferred (area baseline requirement, runtime unit validation,
  quiver cyclic/diverging magnitude semantics, enrichment size definition).
- **S3: 2 recorded** — general nested multi-panel API and richer specialized scale metadata. Neither
  justified schema expansion in this round.

The potentially breaking Bland-Altman change was caught during final audit. The final contract does
not require newly added roles: `mean` and `difference` remain the base input; `agreement_type`,
`center`, and `limits` form an optional all-or-none group. A legacy base input renders only supplied
mean-difference observations. This preserves execution without silently computing scientific
statistics.

## Model-independent scorer

`tests/evaluation/agent_scoring.py` accepts one observable JSON decision per line and calls no LLM.
It reports independently:

- action accuracy;
- render-template and family accuracy;
- input-mode accuracy;
- clarification accuracy;
- require-precomputed accuracy;
- unsupported-scope accuracy;
- scientific-boundary safety rate;
- valid-Figure-Intent rate.

Safety fails when a prediction renders instead of clarifying/requiring upstream analysis, asserts a
forbidden scientific inference, omits case-required scientific roles/semantics, or invents results.
Eleven deterministic scorer tests cover perfect output, wrong action/template, unsafe render,
missing case-required optional role/semantic, unnecessary clarification, missing prediction,
duplicate ID, unknown template and invalid action.

## Multi-panel scientific requirements

General user-data nested multi-panel composition remains outside the public-operable scope; no API
was committed. A future design must preserve these scientific invariants:

1. the same scientific group retains color identity across panels;
2. legends are shared only when grouping semantics match;
3. Colorbars are shared only when quantity, normalization, scale, center, and colormap semantics all
   match;
4. numerical axes are shared only for comparable quantities, units, and scales;
5. different units are never forced onto one numerical axis;
6. panel order belongs to the scientific story, while panel-label geometry remains deterministic;
7. each panel retains its template-specific reference-line semantics.
