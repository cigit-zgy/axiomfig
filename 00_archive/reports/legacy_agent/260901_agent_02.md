## Implementation

### Bar family

The public Bar surface now contains nine Agent-recommended core grammars:

1. `bar.simple`
2. `bar.grouped`
3. `bar.stacked`
4. `bar.normalized_stacked`
5. `bar.grouped_stacked`
6. `bar.diverging_stacked`
7. `bar.range`
8. `bar.mirrored`
9. `bar.waterfall`

Released IDs `bar.vertical`, `bar.horizontal`, and `bar.dot` remain executable compatibility templates. They are excluded from current Agent recommendations and are not presented as core grammars.

`orientation` is a semantic modifier for vertical or horizontal presentation; it does not change the canonical tabular roles. The adapter preserves first-seen ordering and rejects duplicate logical keys, incomplete logical grids, malformed semantic roles, non-finite values, and invalid derived geometry. It never performs hidden `groupby`, mean, sum, or other aggregation.

The family guide at `references/template-knowledge/families/bar.md` documents the scientific role, nine grammar taxonomy, one canonical table per grammar, selection rules, modifiers, scientific boundaries, runtime mapping, and legacy compatibility. Nine external CSV plus Figure Intent examples exercise the public path. No pandas dependency, plotting backend, LLM framework, low-level visual option, nested composition API, or new release/tag was added.
