## Architecture ownership matrix

| Concern | Owner enforced by executable tests |
|---|---|
| Natural-language routing | Agent-facing `SKILL.md` and references; not production runtime |
| LLM/runtime boundary | one five-field `FigureIntent`: template, data, geometry, typography, semantics |
| Template discovery | `templates/index.yaml` only |
| Scientific inputs | family `contract.yaml` plus family adapter |
| Plot grammar | family builders |
| Physical visual defaults | packaged style/color/font YAML and deterministic visual runtime |
| Gallery/evaluation evidence | Gallery, tests and scripts; production cannot import them |
| Validation | public bounded errors and artifact/runtime validators; no scientific repair |

Architecture tests reject production imports from tests/scripts/Gallery/reports/examples, generic runtime
imports from concrete families, cross-family private imports, a second intent schema, low-level intent fields,
and registry/builder drift. Public surface remains 55 templates and five Figure Intent fields.

## Architecture contract implementation

Focused executable tests were preferred over a brittle external import-linter configuration. New gates cover:

- generic-runtime/family dependency direction;
- family isolation and registry/builder identity;
- no evaluation or benchmark leakage into production/wheel;
- tracked-tree hygiene, local absolute paths, oversized files, secrets and broken links;
- single sources of deterministic numeric truth;
- strict package-resource and executable-contract ownership;
- clean wheel and clean checkout user paths.

No agent framework, LLM dependency, scientific-analysis dependency, plugin framework or external plotting
backend was introduced.

## Mypy findings

An initial meaningful run exposed 234 diagnostics when the prior weak suppression posture was removed. The
issues were resolved at their real boundaries with concrete `Mapping`, `Sequence`, `Traversable`, dataclass and
Matplotlib-compatible types rather than blanket ignores. Final result:

```text
python -m mypy src/axiomfig
Success: no issues found in 74 source files
```

Mypy runs in CI on the oldest supported Python (3.11), avoiding Matplotlib annotation drift between CI matrix
members. No global disabled error class or broad package ignore remains.

## Structured-input / duplicate-key hardening

`src/axiomfig/structured_io.py` now supplies one strict YAML loader. Duplicate mapping keys fail closed for
Figure Intent, template registry, family contracts and packaged style/color/font resources. Structured tests
also cover malformed roots, non-string selection keys, duplicate CSV headers, missing CSV values,
heterogeneous JSON rows, invalid Unicode, non-finite or excessively large numbers, malformed contract
containers, and unknown executable keys.

Executable Mantel `link_fields` remains family-owned: the association contract declares it, the Mantel adapter
binds it exactly to `MantelLink`, and generic registry code contains no Mantel exception. Null/missing/extra,
wrong/reordered required/optional fields, malformed/colliding aliases, and silent optional-field loss are
rejected with bounded `ValueError`; contract-defined replacement aliases are demonstrably consumed.

## Bounded public-error findings

Adversarial probes demonstrated and fixed paths that could previously leak `OverflowError`, `TypeError`,
`AttributeError`, `KeyError` or silent Matplotlib fallback from malformed user/config input. Public structured
input now reports bounded domain errors. This did not turn programmer defects into user errors: a builder
`AssertionError` remains visible, while adapter normalization errors are wrapped at the Figure Intent boundary.

The final audit replayed 18 malformed Mantel schema variants through the actual public adapter path and found
no internal exception leakage or silent acceptance.

## Hypothesis/property testing

Property tests cover unknown top-level Figure Intent fields, low-level visual bypass attempts, deterministic
key-order handling, consistent/heterogeneous JSON records, non-finite arrays and finite numeric extremes.
Adversarial scientific-boundary tests preserve SD/SE/CI/PI labels, require explicit diverging centers, reject
analysis requests in plotting semantics, exercise representative family shape failures, and verify parity
limits and dynamic raincloud category counts.

The final full suite collected all Hypothesis, mutation, architecture, package and E2E tests and passed without
shrinking or disabling the properties.
