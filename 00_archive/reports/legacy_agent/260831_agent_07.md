# AxiomFig Figure Anatomy and Complex Capability Audit

## 结论

The audit is complete. Matplotlib core expressed all 20 frozen complex figures with deterministic,
five-run geometry repeatability. The current public AxiomFig Skill rendered one registered control,
clarified two requests, and conservatively rejected 17 unsupported requests. This separates the
dominant product gap—public scientific grammar and composition coverage—from Matplotlib capability.

Three native cases remain deliberately classified `FRAGILE` because dense movable labels and their
connectors required case-local placement. Four external-tool probes justify a later focused
annotation-allocation benchmark, but do not justify a production dependency now.

## Figure Anatomy

`references/figure-anatomy.md` now defines a five-level hierarchy: canvas, region topology, axis
system, scientific artists, and ornaments/annotations. It freezes four placement classes:

- A: data-bound scientific artists;
- B: structurally constrained regions and Axes;
- C: renderer-measured fixed ornaments;
- D: movable annotations with immutable scientific anchors.

The relation vocabulary is `containment`, `alignment`, `anchor`, `minimum_gap`, `equal_size`,
`shared_edge`, `shared_axis`, `aspect`, `ordering`, `non_overlap`, `allowed_overlap`,
`allowed_displacement`, `z_order`, and `ownership`. This is a diagnostic/runtime vocabulary, not a
public DSL, Figure Intent extension, or prompt-visible option set.

## Recurring failure classes

1. Class-D annotations (`T01/T02/T05/E02`): cases 08, 09, 15, and 18 require bounded text movement
   and connector decisions outside ordinary data grammar.
2. Composite topology/shared geometry (`G03/G04`): cases 01, 04, and 13 require explicit region
   reservation or z-order ownership rather than a missing renderer primitive.
3. Public grammar coverage (`S03`): 19/20 complex requests do not reach a registered render despite
   20/20 native feasibility.

## External-tool triggers

The repeated movable-annotation failure class triggered comparative probes. Four PDFs compare
adjustText 1.4.0 and textalloc 1.2.4 on influence and dense-volcano topologies. Both reduced manual
text collisions, but neither resolved scientific connector ownership well enough to justify a
production dependency. The tools remained isolated from the package environment.

## Architecture recommendation

### KEEP

- Figure Intent as the only Agent/runtime boundary.
- Existing deterministic style, typography, Primary Visual Area, and ornament ownership.
- Matplotlib core as the default renderer.

### OPTIMIZE

- Add reusable composite-Axes topology only when a real public template consumes it.
- Replace case-local dense-label lanes with a measured annotation contract only when at least two
  production templates need it.

### ADD

- In a separate round, benchmark one deterministic class-D annotation allocator against cases 08,
  09, 15, and 18. Backend selection and force parameters remain runtime details.

### DEFER

- New public templates, nested user-data composition, domain-specific OncoPrint/UpSet dependencies,
  and any production annotation dependency.
