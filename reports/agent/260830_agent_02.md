# AxiomFig Round 05 Agent 报告

## 1. 结论

Round 05 已完成 Deterministic Layout & Ornament Engine。Panel、panel label、legend、colorbar、spacing 与 geometry validation 已从模板中的隐式副作用收敛为显式 ownership、物理 point token、一次测量求解和运行时失败门禁；74 对 canonical Gallery 已重建、完成一次人工视觉审查与唯一一次修复，最终没有剩余 Important。

## 2. 架构与运行时资源收敛

新增三个窄职责模块：`layout.py` 管理 `FigureLayout`、`PanelFootprint`、Primary/Auxiliary Axes 注册及一次物理布局求解；`ornaments.py` 管理 legend、panel label 与 colorbar tick contract；`anatomy.py` 在 PDF 保存前验证 ownership、等尺寸、对齐、containment、collision 与 output boundary。`template_helpers.py` 删除旧的多面板、colorbar、panel label 与 legend 大段实现，仅保留兼容入口和非布局 artist helper。

运行时资源现在只有 package-local source of truth：

│   ├── licenses/
│   └── 11 font binaries

根目录 `latex/` 已删除，其有效使用说明并入 `references/latex-contract.md`；颜色生成器只更新 package resource。根目录 `fonts/` 连同 11 个开放字体文件和 6 个许可证/attribution 文件迁入 package resources。`typography.py` 改用 `importlib.resources`，clean-wheel E2E 验证字体、license 与 LaTeX 文件在仓库外工作目录仍可发现。Arial、Times New Roman、SimSun 与 Yu Gothic 仍仅是 `bundled: false` 的 optional system metadata。

## 3. Deterministic-first 与上游原则

`SKILL.md` 已把 deterministic-first 固定为硬规则：Agent 只能选择科学意图、既有 template、数据映射、字体模式、geometry preset、palette 和少量科学语义参数；figure size、panel footprint、subplot gap、label/legend/colorbar 坐标、legend 行数与 spacing、bar width、ticks、margin、font/stroke 和 palette 数值均由 runtime 推导，禁止 LLM 临时生成。

本轮审阅 Nicolas P. Rougier 的 *Scientific Visualization: Python + Matplotlib* upstream 与指定 fork，基准 commit 为 `62fa569f30333c817c13e4dc757877c1192fd15a`。采用的原则是显式 Figure/Axes/Artist anatomy、物理单位、GridSpec constraint boundary、ornament 从属于数据、完整 typography/color semantics 与 vector-first validation。AxiomFig 仅记录带 attribution 的设计推论并独立实现；未复制 CC BY-NC-SA 4.0 书稿、图形或 BSD-style code。

## 4. Panel label 根因与 Outer Panel Footprint

Round 04 的不稳定不是 `left_offset_pt` 或 `top_offset_pt` 数值错误，而是 lifecycle 与 ownership 模糊：legend 在 label 出现前测量，旧 helper 可通过 `subplots_adjust(top=...)` 全局移动 panel，family layout 随后再次改变几何，而 label 与 legend 没有共同的最终求解阶段；同时 `outer_panel_bbox()` 只推断 top-level SubplotSpec，没有对象负责 Primary Axes、Auxiliary Axes、local artist 和 Figure-level Ornament。

Round 05 将每个 top-level GridSpec slot 注册为等尺寸 Outer Panel Footprint。11 pt bold panel label 永远锚定 footprint 左上角，再施加唯一的 `-2 pt/+2 pt` 物理 translation，不读取 Primary Axes、colorbar 或 legend bbox。2×2、2×3 与 3×2 的 footprint width/height、同列 x0/x1、同行 y0/y1 均通过严格 geometry assertion。

## 5. Heatmap 与 colorbar containment

Colorbar 被注册为所属 panel 的 Auxiliary Axes。布局求解先保留 panel footprint，再在其内部按 `colorbar_gap_pt = 4.0` 与 `colorbar_width_pt = 9.0` 分配 Primary/Auxiliary Axes；heatmap 的 Primary Axes 可以较窄，但 footprint 与 peer panel 完全相同。运行时 validator 会拒绝任何超出所属 footprint 的 auxiliary axes，因此 colorbar 不能扩大 panel、不能压缩 peer、也不能逃逸到页面外。

Colorbar 使用 out-only tick。普通连续轴的 Matplotlib `inout` major 参数是总长度，因此 colorbar major 从中央 normal major total `6 pt` 推导为 `3 pt`；minor 保持中央 `1.854 pt`，stroke 保持 `main_stroke = 0.8 pt`。

## 6. Legend 内外 spacing

Legend 的全部 spacing 已显式写入 `style.yaml`：

```plain
handlelength   = 1.0
columnspacing  = 1.0
handletextpad  = 0.8
labelspacing   = 0.5
borderpad      = 0.0
borderaxespad  = 0.0
top_gap_pt     = 0.4666666667
```

测量 probe 表明 `columnspacing` 从 Matplotlib 默认 2.0 改为 1.0 后，3-column legend 宽度由 252.75 pt 降为 232.75 pt，两个 column gap 各减少 10 pt；`borderpad=0` 将高度从 18 pt 降为 10 pt；`borderaxespad=0` 将额外外部 gap 从 5 pt 降为 0。Runtime 按 `N, N-1, …, 1` 尝试列数，一行能容纳时禁止降列；registered layout legend 是 Figure-level Ornament，不得移动 panel geometry。

人工审查发现旧单面板 output solver 因 legend 设置 `in_layout=False` 而忽略其 bbox，导致 `02_multi_line` 与 `10_grouped_bar` 上缘裁切。唯一 repair pass 让单面板 margin solve 显式纳入 legend bbox，并重建全部 Gallery；修复后 legend 与 top spine 保持唯一物理 gap，且与页面上缘保留 1.5 pt padding。

## 7. Runtime geometry validation

Registered figure 在最终 typography 与 ornament placement 后、Matplotlib PDF 保存前运行 `validate_figure_anatomy()`。门禁覆盖：footprint 等尺寸和行列对齐、Primary/Auxiliary/local content containment、panel-label anchor/collision/boundary、legend collision/boundary、annotation containment 和 Figure-level Ornament overflow。测试故意把 colorbar 移出 footprint、把 figure text 放到页面外，两者均产生 issue-specific `FigureAnatomyError`，不再输出已知错误 PDF。
