## 2. 规则层与实现边界

```yaml

    width_pt: 9.0
    gap_pt: 6.0
    length_fraction: 0.72
    alignment: center
    tick_side: right
    label_side: right

  mantel:
    matrix:
      source_label_gap_pt: 1.5
      source_group_gap_pt: 4.0
      source_boundary_padding_pt: 3.0
```

旧 `source_label_offset_pt: 12.0`、固定 `xytext=(offset, offset)` 与 Mantel-local
`set_box_aspect(7.0)` 已删除。Figure Intent 仍只表达科学语义，未增加 label、rail、square 或 Colorbar
物理坐标。

## 3. Source label 合同

Source label 不再按 node centre 偏移。布局使用最终字体 renderer 测量 text bbox，并结合 scatter marker
area 与 fill-edge stroke 得到可见 marker radius；label anchor 沿 SourceRail outward normal 放置，使
marker edge 到最近 text edge 的物理距离为 `1.5 pt`。

最终 `render_figure()` 生命周期实测：

| Case | Source 数 | edge-to-edge gaps |
|---|---:|---|
| canonical | 3 | `1.500, 1.500, 1.500 pt` |
| dense | 4 | `1.500, 1.500, 1.500, 1.500 pt` |
| long labels | 3 | `1.500, 1.500, 1.500 pt` |
| multigroup | 4 | `1.500, 1.500, 1.500, 1.500 pt` |

测试容差为 `±0.5 pt`，测试对象是 marker/text 的可见 bbox，不是 node-centre 距离。

## 4. Source packing 与 SourceRail

每个 SourceGroupFootprint 是 marker bbox 与 renderer-measured label bbox 的并集。solver 将 footprint
投影到 SourceRail tangent，按原有科学 source order 以 `4 pt` 可见间距顺序 packing，再把完整 rail
沿 coupling outward normal 推向右上角，直到任一 footprint 激活 `3 pt` Primary Visual Square 边界。
算法为固定两阶段公式求解，无随机、force layout 或迭代优化。

| Case | centre rail span before | centre rail span after | final footprint span | adjacent footprint gaps | boundary clearance |
|---|---:|---:|---:|---|---:|
| canonical | `248.648 pt` | `86.745 pt` | `138.942 pt` | `4.000, 4.000 pt` | `3.000 pt` |
| dense | `250.398 pt` | `108.735 pt` | `140.980 pt` | `4.000, 4.000, 4.000 pt` | `3.000 pt` |
| long labels | n/a | `86.745 pt` | `138.942 pt` | `4.000, 4.000 pt` | `3.000 pt` |
| multigroup | n/a | `110.390 pt` | `144.003 pt` | `4.000, 4.000, 4.000 pt` | `3.000 pt` |

SourceNodes 保持共线，SourceRail 与 TargetRail 保持平行。canonical 的 rail-to-target perpendicular
distance 从 `54.327 pt` 变为 `51.865 pt`；dense 从 `56.911 pt` 变为 `62.398 pt`。canonical 的绝对值
没有增加，是因为全局 Colorbar reservation 后最终 Primary Visual Square 从 `281.313 pt` 调整为
`206.932 pt`。新的正确性证据是 measured footprint 已触发 `3 pt` 外边界且再向外移动 `1 pt` 将违反
边界，不是依赖固定 rail depth。Source group tangent span 的大幅压缩使实际曲线扇形更清楚。

## 5. Square geometry

Mantel 将 matrix 与 complementary coupling triangle 注册为一个 Primary Visual Square。layout 先保留
外部 ornaments，再 fit 最大正方形；runtime anatomy validation 在最终 draw 后测量 data transform，要求
square 误差不超过 `0.5 px`、cell aspect 误差不超过 `0.1 px`。

| Case | Primary width | Primary height | error | cell width | cell height |
|---|---:|---:|---:|---:|---:|
| canonical sans | `206.932 pt` | `206.932 pt` | `0.000 px` | `20.693 pt` | `20.693 pt` |
| dense sans | `209.162 pt` | `209.162 pt` | `0.000 px` | `14.940 pt` | `14.940 pt` |
| long-label sans | `279.726 pt` | `279.726 pt` | `0.000 px` | `27.973 pt` | `27.973 pt` |
| multigroup sans | `200.103 pt` | `200.103 pt` | `0.000 px` | `16.675 pt` | `16.675 pt` |

Serif canonical 同样通过相同 renderer gate。测试另行将 axis aspect 人为改为 `auto`，确认 validator 会以
`primary visual square` 错误拒绝失真的 figure。

## 6. Global Colorbar contract

文档统一使用术语 Colorbar：它是 continuous color scale / continuous color legend，不是 categorical
legend。通用尺寸由 `style.yaml` 拥有；`layout.py` 分配 registered Auxiliary Axes；`ornaments.py` 应用
filled-axis tick 与 right-side label contract；Mantel 只提供 Pearson scalar mapping、ticks 和 label。

Canonical Pearson Colorbar renderer 实测：

```plain
orientation:          vertical
position:             outside-right
alignment:            centered on Primary Visual Square
rendered length:      148.991 pt
length fraction:      0.72000
width:                9.000 pt
gap:                  6.000 pt
vertical centre error: 0.000 pt
ticks:                -1.0, -0.5, 0.0, 0.5, 1.0
label:                Pearson r
```

Dense 的 rendered length 为 `150.597 pt`，同样为 square height 的 `0.72`。原 Colorbar 长度为固定
`63 pt`，canonical 比例仅 `0.22395`，且距 matrix `102.417 pt`、垂直中心误差 `18.777 pt`；这些
Mantel-local 几何已被全局合同替代。

## 10. Remaining limitations

Renderer measurement does not shrink source fonts or use stochastic packing. If a future user supplies source-group
footprints that physically cannot fit inside the selected Primary Visual Square, the solver raises a clear error rather
than violate the `1.5 / 4 / 3 pt` contract. The new reusable Colorbar contract currently specifies the required vertical,
outside-right square-reference case; no horizontal Colorbar contract was added because this round has no consumer.
