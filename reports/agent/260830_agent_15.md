## 4. 永久合同与实现

### 4.1 连续 count 色标

`scatter/hexbin` 现在通过注册的 panel layout 创建 Auxiliary Colorbar Axes，并复用既有 global vertical
Colorbar contract。默认 label 为 `Count`；原 `count_label` 字段改为该 Colorbar 的语义 label，不再在
数据区左上角生成与颜色映射脱节的普通文字。

该修复没有修改 Colorbar 的 `9 pt` width、`6 pt` gap、`0.72` length fraction、right ticks 或
right label。`tests/test_primary_area_layout.py` 已把 hexbin 加入所有生产 vertical Colorbar consumer 的
统一 renderer 测试。

### 4.2 Distribution raw-point 合同

`style.yaml` 新增唯一 family token：

```yaml
plots:
  distribution:
    raw_point_size_pt2: 20.0
    ecdf_max_markers: 12
```

strip 和 raincloud 通过 `apply_distribution_point_contract()` 复用 scatter 的 `0.55` face alpha、
opaque black edge 与 `fill_edge` stroke，仅把密集原始观测的 marker area 收敛为 `20 pt²`。这是一项有
两个真实消费者的 family contract，没有改变普通 scatter、ordination、diagnostics 或 omics marker。

ECDF 保留中央 series color/linestyle/marker grammar，但按每条 series 的样本数确定 `markevery`，最多绘制
12 个 marker。step curve 因此恢复为主要科学 artist，LLM 不需要选择 marker sampling。

### 4.3 Quiver 边界保护

Quiver 的 source grid 现在按每个坐标方向的实际网格间隔计算 half-cell padding，再交给 deterministic
nice-axis helper。坐标范围不再终止于最外侧 vector anchor，边界 arrowhead 和 shaft 均位于 axes 内。
该规则只属于 vector field grammar，没有改变 contour 或普通 numeric axis 的 limits。

## 5. Before/after 视觉证据

实际打开并比较的临时证据位于：

- `tmp/gallery-audit/comparisons/G001/`：hexbin 无 Colorbar 与 global Colorbar；
- `tmp/gallery-audit/comparisons/G002/`：quiver 边界裁切与 half-grid padding；
- `tmp/gallery-audit/comparisons/G003/`：ECDF 全样本 marker 与 bounded marker sampling；
- `tmp/gallery-audit/comparisons/G004/`：strip/raincloud 的 `36 pt²` 与 `20 pt²` raw points。

最终直接打开受影响的 5 张 sans 和 5 张 serif PNG。结果如下：

- hexbin 的 count scale 可解释，Colorbar 保持次要层级且未压缩成不可读数据区；
- quiver 四侧箭头完整，Colorbar 与 contour/omics/Mantel 消费者保持相同几何；
- ECDF marker 不再形成覆盖 step curve 的连续粗带；
- strip/raincloud 的 black edges 仍保持清晰，但 raw points 不再压过 distribution geometry；
- sans 与 serif 的 limits、axes、Colorbar 和 artist hierarchy 保持等价。

最终又打开 15 张 family/technical/layout contact sheets，复核全部受影响模板及相邻消费者。未发现 Mantel、
heatmap、line、bar、estimation、diagnostics、flow、survival 或 multi-panel regression。

## 8. 文档与剩余视觉债务

`references/style-contract.md` 仅增加两类已投入生产的规则：dense distribution raw points/ECDF marker
sampling，以及 quantitative hexbin 必须使用 global Colorbar。没有扩充 `SKILL.md`、Template Registry
或 Figure Intent，Agent discovery token estimate 保持 `1629`。

剩余视觉债务为两个明确的局部 P2：PCA biplot loading label 需要 renderer-aware physical offset；
volcano canonical fixture 需要更有代表性的高显著性 tails。二者不共享同一根因，不足以升级为全局
contract。本轮未为了追求零问题而修改其统计语义、示例数据或 unrelated templates。
