# AxiomFig v1 架构清理与公开发布报告

## 1. 结论

AxiomFig v1 已完成发布前架构收口。清理没有新增模板或改变科学绘图能力；55 个公开模板、
13 个 plot family、28 个 direct-data path、27 个 precomputed-result path、0 个
canonical-only template 和 112 对 Gallery artifact 均保持不变。运行时、wheel、Figure Intent、
CLI、fresh clone 与 GitHub Actions 已通过发布候选验证。

任务开始时，本地 `master`、`origin/master` 与 GitHub `master` 均为
`51425adf2e565a069ce7c1dde2b3598dd2ced369`。架构清理 release candidate 为
`f8650be0a035a4a00e6a240685fbeafefadad2eb`。本报告采用项目既有的 report-only commit
约定：`v1.0.0` 指向包含本报告的最终提交；该提交和 annotated tag object 的精确 SHA 在发布后
由 Git、GitHub tag 与 GitHub Release 三方核验，避免在报告自身中虚构循环引用 SHA。

## 3. 生产模块收敛

顶层 production modules 从 16 个减为 12 个：

```plain
before
__init__.py  anatomy.py  cli.py  colors.py  config.py  contracts.py
evaluation.py  gallery.py  intent.py  latex.py  layout.py  ornaments.py

after
__init__.py  cli.py  config.py  gallery.py  intent.py  latex.py
layout.py  ornaments.py  rendering.py  style.py  typography.py  validation.py
```

每个保留模块只有一个系统职责：

| 模块 | 职责 |
|---|---|
| `__init__.py` | 版本与最小 public package surface |
| `cli.py` | 四个 console entry point |
| `config.py` | packaged YAML contract 加载与 rcParams 构造 |
| `style.py` | 颜色、stroke、ticks、nice axis 与 artist visual contract |
| `layout.py` | single/multi-panel geometry 与 output fitting |
| `ornaments.py` | legend、panel label、colorbar ownership 与 placement |
| `typography.py` | bundled font discovery 与语言文本行为 |
| `latex.py` | Tectonic finalization 与 technical probe |
| `rendering.py` | vector-first PDF/PNG render pipeline |
| `validation.py` | runtime Figure、PDF artifact 与 Gallery trust boundary |
| `intent.py` | 最小 Figure Intent parsing、data mapping 与执行入口 |
| `gallery.py` | registry-driven canonical Gallery generation |

`template_helpers.py`、`colors.py` 与 `contracts.py` 合并为明确的 `style.py`；其中 layout、
ornament 和 typography 逻辑分别移回所属模块。`anatomy.py` 合并到 `validation.py`，保留原有
异常、issue message、panel footprint、containment、collision、font、Type 3 与 PDF boundary
检查。`evaluation.py` 移到 `tests/evaluation/run.py`，不再作为用户运行时模块安装。

## 4. Template adapter 与单一事实源

平行的 `src/axiomfig/data_adapters/` taxonomy 已删除。13 个 family adapter 分别与 builder 和
contract 同址：

```plain
src/axiomfig/templates/<family>/
├── builders.py
├── adapter.py
└── contract.yaml
```

Builder 仍只负责 plot grammar，adapter 只负责 direct/precomputed input normalization 与
validation。每个 public variant 的 `input_mode` 现在写在 family `contract.yaml`；运行时从
contract 机械推导 28 direct、27 precomputed、0 canonical-only，不再维护全局手写分类 set。
小型 `__init__.py` 被保留，因为 root registry 使用显式 `BUILDERS` import，避免动态 import
magic；`heatmap` 的可复用 primitive 也继续拥有明确 public import。

## 5. Runtime resources 与 wheel

三个视觉配置源已从根目录移入：

```plain
src/axiomfig/resources/styles/
├── style.yaml
├── fonts.yaml
└── colors.yaml
```

`config.py` 使用 `importlib.resources`；source checkout 与 installed wheel 读取同一份 packaged
resource。`pyproject.toml` 删除了 `data-files` 与 `share/axiomfig` fallback，只打包 styles、
fonts、font licenses、LaTeX resources、Template Registry 和 family contracts。

第一次 wheel 审计发现旧根 `build/` 会把已删除模块重新带入 wheel；该缓存随后被移出仓库并从
干净状态重建。最终 wheel 为 1,617,083 bytes、99 个 archive entries，其中 93 个
`axiomfig/` entries；包含 3 个 style YAML、13 个 family adapter 和 14 个 contract，不包含
Evaluation corpus、references、reports、Gallery、`share/axiomfig` 或旧模块。干净 wheel SHA-256
为 `e8d67c9081eea0919858bd0a6f63e09a6cfae66324ddfca30775e302e7f6bb7a`。

runtime、artifact、CLI 和 fresh-clone 验证。

labels 尚非 TeX-native；specialized variants 继续作为 post-v1 工作。Animation、interactive
dashboard、large 3D、microscopy、chemical structure 与 GIS 不属于 v1。发布候选上没有剩余
Important defect。
