保留 `src/axiomfig/`，因为该层承担 package namespace、editable/wheel installation、CLI entry point 与 package resource boundary。拍平到 `src/` 会破坏标准 src-layout，不属于有效简化。

内部审计确认 `config.py`、`contracts.py`、`template_helpers.py`、四个 template family、`gallery.py`、`latex.py`、`typography.py`、`rendering.py` 和 `validation.py` 均具有独立职责，因此未机械合并模块。已删除未注册、无消费者的 `build_multi_panel()` forwarding alias；canonical registry 现在只包含 36 个实际 builder。

## 3. 视觉合同

### 3.1 Alpha 与边框

scatter、bar、violin、boxplot、CI 和 histogram 不再调用 artist-wide alpha。helper 直接构造 face RGBA，并把 edge RGBA 固定为 opaque black。中央边框宽度保持 `fill_edge = 0.6 pt`；测试分别检查 face alpha 小于 1、edge alpha 等于 1。

### 3.2 Tick geometry 与 errorbar 根因

Round 03 的 minor tick 为 `1.236 pt`。Round 04 将其乘以 1.5，得到 `1.854 pt`，并由一个中央关系推导 major：

```plain
phi = 0.6180339887
major inward projection = 1.854 / phi
Matplotlib inout major parameter = 2 × 1.854 / phi
                                = 5.9996700308 pt
```

实际 raster probe 确认 Matplotlib `inout` length 约有一半投向 axes 内部。open axis 使用 major `inout`、minor `in`；filled numeric axis 和 colorbar 复用相同物理长度，方向为 `out`。

serif errorbar 的最小复现显示 sans/serif 使用相同的唯一 locator、tick direction 和中央长度，不存在 duplicate locator、errorbar overlap 或 style leakage。旧视觉缺陷来自过短的中央 minor tick 在 serif 输出中表现为不协调的短 stub，而不是 errorbar template 的局部状态。修复中央长度后，sans/serif errorbar 与普通 line/multi-panel 一致。

### 3.3 Legend、bar 与 series identity

Legend gap 从 `0.7 pt` 缩短为 `0.4666666667 pt`。多 series legend 按 `N, N-1, …, 1` 尝试 column 数，接受第一个不越过 figure boundary 且不碰 panel label 的候选；不再因为宽于 data axes 就提前换行。`02_multi_line` 已恢复一行。

Bar width 由 YAML 固定为 single `0.60`、group total `0.76`，grouped individual width 为 `0.76 / n_series`，不随 3、5、10 个 category 改变。2-series 与 4-series geometry probe 已覆盖。

统一 series cycle 同时编码 color、linestyle 和 marker。前四项为 solid/circle、dash-dot/square、dotted/triangle、long-dash/diamond；long-dash pattern 为 `6 pt on, 2 pt off`。secondary/reference line 默认 dash-dot。

## 4. Layout 与 panel label

`references/layout.md` 现在正式区分：

- outer panel footprint：top-level GridSpec slot；
- inner data axes：panel 内承载数据的 axes；
- auxiliary axes：panel 内的 colorbar 等支持 axes。

2×2、2×3 和 3×2 的 outer footprint 均严格等尺寸。Heatmap panel 使用 nested GridSpec，在自己的 footprint 内分配 data axes、gap 和 colorbar；colorbar 不再向 panel 外伸出，也不压缩 peer panel。

Panel label 为 11 pt bold，并以 outer footprint 左上角为 anchor，使用 `-2 pt` horizontal、`+2 pt` vertical physical offset。第一次视觉审查发现 figure-level label 在后续 family layout/fixed-page solver 后没有刷新；repair pass 增加动态 re-anchor，使 subplot geometry 每次变化后重新定位 label。`33_two_panel`、`34_four_panel`、`35_six_panel` 和 `36_complex_multi_panel` 已通过 offset 与 symmetry probe。

## 5. Typography、palette 与 Tectonic

Sans mode 的 text 与 Matplotlib MathText regular/italic/bold 全部映射到 Latin Modern Sans。`gallery/sans/08_regression_scatter.pdf` 的 `R^2` 只嵌入 LMSans10-Regular；serif 对应图嵌入 XCharter Roman 与 XCharter Math。R²、Greek、subscript 和 superscript 不再出现局部 serif contamination。

`colors.yaml` 现在包含五套八色 Axiom palette：Classic、Soft、Deep、Warm、Cool；同时保留 Tol Bright、Tol Muted 和 grayscale。生成器从同一 YAML 同步生成 repository/package xcolor 文件，并提供 canonical short name 与 palette-qualified name。

新增真实 Tectonic-native Gallery：

- `gallery/latex/01_scientific_typography.pdf/png`：`siunitx` unit、`mhchem` chemistry、`amsmath`/`unicode-math` formula；
- `gallery/latex/02_palettes.pdf/png`：五套 Axiom palette comparison。

视觉审查发现 palette `\colorbox` 内的黑色 `\rule` 遮住 background；repair pass 改为带尺寸的 invisible phantom，使 swatch 显示真实填色。Matplotlib figures 仍是先嵌入文字再由 Tectonic finalization；没有声称 Matplotlib label 已由 TeX-native 排版。

## 6. Statistical Gallery

Sans 与 serif 各有 36 个同步案例，覆盖 line/CI/scatter/bar/distribution、density、ECDF、forest、point interval、Bland-Altman、heatmap/correlation/preordered cluster/confusion matrix、ROC、PR、calibration、residual diagnostics、Mantel、model evaluation 和四种 multi-panel layout。
