# AxiomFig 完整 120-case Progressive-Disclosure Blind Agent Benchmark

## 结论

**Verdict: PASS（benchmark protocol）。** 本轮在冻结 AxiomFig 产品层的前提下，完成了全部
120 个 case 的 progressive-disclosure blind benchmark。每个 case 是一个独立逻辑 context；broker
交互共启动 486 个 fresh、ephemeral Codex session，session ID 全部不同。gold、scorer、reports、`.git`、
host skills、shell、browser、plugins、network tools 和 subagents 均未进入 Agent 可见面。

严格 parser 接受 `100/120` 个输出；20 个输出虽然是 JSON，但违反 observable schema 或生成了无效
Figure Intent，因此按冻结协议保留为失败，没有重跑。严格 scorer 的 action accuracy 为
`91/120 = 75.83%`，render-template accuracy 为 `61/70 = 87.14%`，scientific-boundary safety 为
`97/120 = 80.83%`。对 20 个被拒 raw outputs 的独立科学审阅表明，14 个
`require_precomputed` case 实际选择了正确的科学 action，但没有满足机器接口。把 raw observable
decision 与 parser 合规性分开后，action 为 `108/120 = 90.00%`，人工审阅的科学安全为
`119/120 = 99.17%`；这些后置审阅结果不替代严格 scorer 指标。

本轮没有修改 SKILL、knowledge、family contracts、Figure Intent、templates、runtime 或 Gallery。
实现提交为 `38f266ab29667d21383fa0ab34855c481af8db1e`。本报告由后续 report-only commit 收录；Markdown
文件无法可靠包含自身 commit SHA，因此最终 report-only SHA 与其 CI 在任务最终 checkpoint 中给出。

## Isolation and adversarial probes

`ProgressiveReadBroker` 只允许：

- `SKILL.md`；
- Agent protocol、Figure Intent、Mantel reference；
- template-knowledge index 与 routed topics；
- template registry；
- 一个 family contract。

它拒绝 absolute path、`..`、glob、directory listing、symlink、`.git`、reports、tmp、Gallery、gold、
scorer 和非文件路径。确定性测试覆盖 allow/deny、traversal、absolute path、symlink escape、gold、scorer、
reports、`.git`、wildcard 与 shell-like request。

正式 benchmark 前的四个 fresh Agent probe 分别请求 hidden gold、absolute path、wildcard 与 previous
report；四次均由 broker 拒绝。另一个 tool-surface probe 对 gold read、repository enumeration、shell、
network、plugins/MCP、host skills 和 subagent 均返回不可用。被评分 120 个 case 没有越权请求，
`denied_reads = 0`；这表示正常路由没有触发 deny，不表示 deny path 未测试。

预备实现曾尝试通过 Codex CLI 暴露自定义 MCP read tool，但当前 CLI 环境不能可靠启动该工具；该未计分
路径被删除。随后发现 Codex App session 环境变量会暴露额外工具名称，因此 runner 显式移除
`CODEX_APP_TOOLS_PIPE_PATH`、`CODEX_MCP_NODE_PATH`、`CODEX_PERMISSION_PROFILE`、
`CODEX_SESSION_ID` 与 `CODEX_THREAD_ID`，并在正式 120-case run 前重新通过对抗探针。

## Progressive-disclosure architecture

每个 Agent 初始只收到 researcher request、available data/schema 与顶层 `SKILL.md`。每个后续 turn
只能返回 `{"read":"relative/path"}` 或最终 11-field decision。Broker 返回的历史仅包含同一 case
此前成功读取的 AxiomFig 文件。最终输出不收集 chain-of-thought。

120 个 case 中，`references/agent-protocol.md` 被读取 120 次；registry 81 次；Figure Intent 68 次；
knowledge index 10 次；五个 routed knowledge topics 合计 8 次。没有重复读取同一文件，没有读取
builder/runtime implementation，也没有无关 Mantel 扩张。
