# AxiomFig v1 Figure Intent 闭环与 Release Freeze 报告

## 1. 结论

AxiomFig v1 的公开能力与真实执行路径现已一致：55 个 public template 全部具有显式
external-data 或 precomputed-result contract，并全部通过 Figure Intent、family adapter、
canonical builder、runtime anatomy、Tectonic PDF/PNG 和最终 PDF validator。Canonical-only
数量为 0，本轮没有扩展 taxonomy、模板或视觉合同。

任务开始时核验的本地、`origin/master` 与 GitHub `master` 基线均为
`01da286a5b1e178976d51986571fe22c56483acb`。最终验证的实现 SHA 为
`ba9debd7021d60792e037fef4abbb038ec063b1f`。本报告随后以 report-only commit 提交，
因此最终 remote SHA 在 push 后由本地、`origin/master` 与 GitHub 三方核验，不在报告正文
中虚构自引用 commit。

## 2. Operability contract

`references/figure-intent-coverage.md` 冻结并记录了全部 55 个公开模板的输入分类：

| 状态 | 数量 |
|---|---:|
| Public templates | 55 |
| Direct user-data templates | 28 |
| Precomputed-result templates | 27 |
| External/precomputed-data operable | 55 |
| Canonical-only | 0 |

Direct-data 模板接收 observation vector、categorical record、matrix、grid 或 flow record。
Precomputed-result 模板接收明确的 regression line、uncertainty interval、diagnostic curve、
ordination coordinates、Mantel relationships、adjusted p-values 或 survival curve。绘图层不
训练模型，也不计算 clustering、PCA/PCoA/NMDS、Mantel statistics、adjusted p-values、
confidence intervals 或 survival estimates。

每个 family 的 `contract.yaml` 是数据角色的发现入口。`data_adapters/` 按 13 个 family
组织普通显式 Python adapter；adapter 验证 required/optional roles、基本 shape、有限值、
区间、标签和引用关系，并将 normalized kwargs 传给 builder。未知字段、缺失字段、错误 shape
或没有科学语义的输入会明确失败，不会静默丢弃用户数据。

## 3. Figure Intent

Figure Intent 仍保持最小边界：

```yaml
template: scatter.parity
data:
  observed: measured
  predicted: simulated
typography: sans
```

用户只声明 template、data mapping、可选 typography/geometry 和必须显式的科学 semantics。
字体字号、linewidth、tick length、legend/panel/colorbar 坐标、bar width、subplot spacing 和
figure dimensions 继续被禁止。若 geometry 省略，运行时现在采用 Template Registry 中该
模板的 geometry，而不是统一硬编码 90 mm；真实 Mantel E2E 因此自动使用其 140 mm
`onehalf-column` contract。

## 4. Adapter 与 builder 完成情况

本轮补齐 line、scatter、bar、distribution、heatmap、estimation、diagnostics、ordination、
association、flow、field、omics 和 survival 的 data-bearing builder path。关键科学边界包括：

- regression 只绘制外部 supplied fitted values，不自动拟合；
- clustered heatmap 接收显式 row/column order，不引入 clustering dependency；
- PCA/PCoA/NMDS 接收预计算 coordinates、loadings、variance、stress 或 distance metadata；
- Mantel 接收 correlation matrix、structured links、strength 和 significance；
- Kaplan-Meier 接收 visualization-ready survival probability、group、CI 和 censoring；
- volcano 与 enrichment 接收已计算 effect、adjusted significance 和 enrichment result；
- Sankey 使用原生 Matplotlib 的确定性 layout，不新增大型第三方依赖。

无参数 canonical builder 路径继续保留，Gallery 因此无需由评估 fixture 重建。外部数据
fixture 只位于 `evaluation/`，没有污染 canonical Gallery。

## 5. True data-driven Evaluation

`evaluation/cases.yaml` 现在包含 55 个 case，与 public template ID 一一对应。每个 case
具有 `id`、`scientific_intent`、`expected_template`、`fixture`、`figure_intent` 和
`expected_validation`。`evaluation/fixtures.yaml` 提供 13 个 family-level 小型确定性数据集，
并随 wheel 安装。

最终 `scripts/evaluate_release.py --output tmp/release-evaluation` 实测结果：

| 指标 | 结果 |
|---|---:|
| Routing | 55/55 |
| Canonical rendering | 55/55 |
| External-data rendering | 55/55 |
| Runtime anatomy validation | 55/55 |
| Tectonic PDF/PNG + final validator | 55/55 |
| Gallery template coverage | 55/55 |
| Repeatability subset | 7/7 |

Repeatability subset为 `scatter/parity`、`heatmap/correlation`、`association/mantel`、
`ordination/pca_biplot`、`flow/sankey`、`omics/volcano` 和
`survival/kaplan_meier`。同一 Figure Intent 与同一 fixture 重复渲染的 RGBA visual
signature 全部一致；没有要求包含时间 metadata 的 PDF byte-for-byte 相同。完整 release
Evaluation 用时 65.97 s，failures 为空。

## 6. Runtime validation 与 Gallery

每个 external-data case 均经过既有 runtime gate：Artist ownership、Outer Panel Footprint、
Primary/Auxiliary containment、legend/panel-label/annotation collision、overflow、clipping、
colorbar、font family 和 panel symmetry。55 个 release artifact 随后逐一经过 Tectonic、
Poppler、PDF parse、embedded/subset font、Type 3 rejection 和 page-boundary validation。

Gallery 保持 canonical registry catalog，不由 arbitrary external data 重建。最终现有 Gallery
验证为 112 对：sans 55、serif 55、technical/latex 2；所有 PDF 均有对应 PNG，public
registry coverage 为 55/55，无 orphan、无 numeric flat artifact。本轮没有调整 palette、
stroke、ticks、legend、panel label、font 或 taxonomy。

## 7. CLI、安装与 fresh clone

自动测试通过 13 个 family 的 YAML Intent + JSON data CLI path。隔离 wheel 测试在临时
`venv --system-site-packages` 中安装构建出的 wheel，并用 installed `axiomfig-intent` 实际
生成及验证 13 PDF + 13 PNG：line、scatter、bar、distribution、heatmap、estimation、
diagnostics、ordination、association/Mantel、flow、field、omics 和 survival，结果 13/13
PASS，用时 19.34 s。

最终从 GitHub `master` 的 SHA
`ba9debd7021d60792e037fef4abbb038ec063b1f` 做 fresh clone，在独立临时 venv 中安装，
随后真实执行任务要求的 12 个代表 family，生成并验证 12 PDF + 12 PNG，结果 12/12 PASS。
Styles、fonts、font licenses、LaTeX resources、Template Registry、family contracts、Knowledge
index、Evaluation cases 和 fixtures 均可从安装包发现，不依赖 repository root 或用户隐藏
状态。
