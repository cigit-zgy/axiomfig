## 2. 根因与移除的旧行为

before 图已重新渲染并实际打开。旧实现存在两个直接原因：

- SourceNode 使用 `(0.46, 0.68, 0.54, 0.72)` 交替 depth pattern，三个或更多源点不共线；
- 每条 link 独立执行 lane candidate、obstacle、crossing、proximity、route length 与 envelope scoring，
  因而产生不一致的双三次曲线形态。

本轮删除了 `_lane_fractions`、`_route_interference`、`selected_routes`、proximity penalties、
envelope search、depth pattern 与 previous-route state。`coupling.py` 相对基线删除 344 行、新增 49 行，
净减少 295 行。没有保留兼容路径或死代码。

## 3. SourceRail

TargetRail 方向为 `(1, -1)`。对 triangular Mantel，coupling normal 为：

```plain
lower:  (1, 1) / sqrt(2)
upper: -(1, 1) / sqrt(2)
```

SourceRail 由 TargetRail 沿 coupling normal 平移一个确定性距离得到。该距离由 matrix size、renderer
测得的 source-label width/height、source count、label offset 与 minimum clearance 共同约束。rail
端点使用同一 normalized interval，SourceNode 按原始科学 source order 通过 `linspace` 单调分布。

自动测试覆盖 1、2、3、5 个 source group，并同时覆盖 lower/upper orientation。正式 Gallery 的实测值：

| Case | Sources | 最大共线误差 | 与 TargetRail 最大平行误差 | rail 距离 |
|---|---:|---:|---:|---:|
| canonical | 3 | `2.243e-16` | `2.115e-16` | 19.986 pt |
| dense | 4 | `3.204e-16` | `0.000e+00` | 32.380 pt |
| long labels | 3 | `0.000e+00` | `0.000e+00` | 42.707 pt |
| multigroup | 4 | `1.495e-15` | `9.612e-17` | 27.322 pt |

所有 source label 使用同一法向侧、同一 alignment 原则与同一 point-space offset；长 source name 继续使用
renderer-measured word-boundary wrapping。

## 4. Node contract

Mantel node 改为 `Axes.scatter()` 产生的 `PathCollection`，不再使用 data-coordinate `Circle` radius。

```plain
scatter base marker area: 36.0 pt²
SourceNode ratio:         1.35
SourceNode area:          48.6 pt²
TargetNode ratio:         1.0
TargetNode area:          36.0 pt²
face alpha:               0.55
edge:                     opaque black
edge width:               fill_edge = 0.6 pt
```

SourceNode fill 由 `series_style(source_index)` 决定；TargetNode 使用统一 Axiom neutral fill。link color 仍只
编码 Mantel P value，link width 仍只编码 `abs(Mantel r)`。以下 Mantel 专用重复 token 已删除：

- `source_node_radius`、`target_node_radius`；
- source/target node fill 与 edge color；
- `route_clearance`、`route_lane_spacing`。

`style.yaml` 只保留 `source_size_ratio: 1.35`、`target_size_ratio: 1.0` 与统一
`curve_curvature: 0.18`。基础 marker size 仍只有 scatter contract 一个来源。

## 5. Unified curve grammar

每条 link 只依赖 source point、target point、orientation、共享 curvature magnitude 与 curvature sign。
primitive 为单一 quadratic Bezier：

```plain
MOVETO SourceNode centre
CURVE3 shared-rule control point
CURVE3 TargetNode centre
```

共享 curvature magnitude 为 `0.18`。按 ordered target index 分割符号：

```plain
target_index < target_count / 2  -> -1
target_index >= target_count / 2 -> +1
```

奇数 target count 的 centre target 确定性地归入第二半。每条 curve 的首尾点与 SourceNode/TargetNode
中心严格相等；不存在 waypoint、S bend、lane search 或 previous-route dependency。10、15、20 variable
quality gate 的 link/matrix intersection 与 link/source-label intersection 均为 0。

## 8. 保留能力与限制

55 个 public template、Figure Intent、7 Mantel glyph、matrix masks、ordering、significance、CI、cluster、
continuous width、advanced 4-bin P-value、fonts 与 Tectonic 均保持不变。

统一 quadratic grammar 以视觉一致性为目标，不再尝试对任意 dense graph 做 crossing optimization；
极高密度外部 Mantel result 仍可能发生必要的 curve intersections。AxiomFig 保证确定性、端点正确、
rail geometry、matrix containment 与现有 collision gates，不承诺任意网络的无交叉平面嵌入。Mantel
statistics 与 Pearson statistics 仍必须由上游提供。
