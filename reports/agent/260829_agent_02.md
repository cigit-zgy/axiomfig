## 9. Tectonic / LaTeX hard investigation

### 9.1 成功边界

Standalone axiomfig.sty 通过 Tectonic 原生排版以下通用 scientific semantics：

~~~latex
\qty{10}{\milli\gram\per\litre}
~~~

Package 只加载 generated xcolor、siunitx、mhchem、amsmath 和 unicode-math，不定义 COD、BOD、ASM、ADM 等领域宏。

### 9.2 精确失败

真实 Matplotlib PGF experiment：

~~~python
import matplotlib as mpl

mpl.use("pgf")
mpl.rcParams["pgf.texsystem"] = "tectonic"
~~~

Matplotlib 3.10.9 与 Tectonic 0.17.0 的精确失败为：

~~~plain
ValueError: Key pgf.texsystem: 'tectonic' is not a valid value for pgf.texsystem; supported values are ['xelatex', 'lualatex', 'pdflatex']
~~~

把 siunitx macro 放入 MathText 的精确边界为：

~~~plain
\qty{10}{\milli\gram\per\litre}
^
ParseFatalException: Unknown symbol: \qty, found '\'  (at char 0), (line:1, col:1)
~~~

把 macro 放在 MathText 之外只会在 intermediate PDF 中形成 literal command text。外层 Tectonic wrapper 接收到的已经是完成 shaping 的矢量 PDF，不能回溯并展开其中的 macro。

### 9.3 Verdict

**Matplotlib-internal siunitx / mhchem text：TECHNICALLY BLOCKED / DEFERRED。**

本轮保留稳定 vector PDF -> includegraphics wrapper -> Tectonic final PDF 路径。没有使用 alternate TeX engine、backend monkey patch 或脆弱的字符串替换。未来路线必须先在隔离 prototype 中证明 Tectonic macro expansion、字体、文本提取、物理几何、错误处理和完整 PDF/PNG pipeline，再进入 production。
