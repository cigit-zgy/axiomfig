## Decision-contract architecture

最终 observable contract 是四个 exact-key variants。所有 variant 都拒绝 unknown field、缺失 required
field 与空 required text；不适用字段必须 absent，不能用 `null` 或 provisional render boilerplate 填充。

| Action | Required | Optional | Validation |
|---|---|---|---|
| `render` | `action`, `template`, `input_mode`, `mapped_roles`, `scientific_semantics`, `scientific_inferences`, `figure_intent` | none | template registered；input mode 与 family contract 一致；`mapped_roles` 是 role → one supplied key；Figure Intent 可解析，template/data 与 observable fields 一致 |
| `clarify` | `action`, `question`, `reason` | none | 问题和原因均为非空文本；不允许 provisional template/mapping |
| `require_precomputed` | `action`, `missing_result`, `reason` | `candidate_template` | missing result 与原因显式；candidate 如存在必须是 registered precomputed template |
| `unsupported` | `action`, `reason` | none | reason 显式描述缺失的 public scientific/visual grammar |

实现采用现有 Python mapping/parser，不引入 Pydantic、LLM SDK、Agent runtime package 或第二个 public
intent schema。Figure Intent 仍是唯一 LLM → deterministic plotting runtime boundary。

## Field ownership

- `mapped_roles` 仅属于 executable `render`，因为生产 adapter 只消费 role → one dataset key。多个
  scientific series 由对应 dataset value 的矩阵/数组表达，不把一个 role 扩成任意 column list。
- `scientific_semantics` 与 `scientific_inferences` 仅用于 render decision 的可观察科学边界；实际执行
  仍由有效 Figure Intent 承载 data/semantics。
- `clarify.question` 只询问缺失的 material scientific distinction；不要求提前选择最终 template。
- `require_precomputed.missing_result` 说明缺少什么上游结果；`candidate_template` 只在下游图已确定时
  使用，不代表已形成 Figure Intent。
- `unsupported.reason` 说明 public grammar 缺失；不能静默降级为「先做上游计算即可」。

## Semantic alias policy

Scorer 只做 finite、explicit、scientifically equivalent 的 exact normalization：

- `SE`、`standard error`、`standard_error` → `SE`；
- `prediction_interval`、`prediction interval`、`95 percent prediction interval`、
  `95% prediction interval` → `prediction_interval`。

明确不合并：SD ↔ SE、confidence interval ↔ prediction interval。没有 fuzzy matching、embedding、
LLM adjudication 或 substring guessing。Scorer 同时从有效 Figure Intent 读取 `center: 0`，并识别显式
numeric `reference/null/null_reference: 1`；这修复了新 benchmark 中 N03/N04 的两个 harness false
unsafe，不改变 Agent 输出，也没有重跑 case。

## R33 scientific-reference ownership

R33 request 明确 effect type 是 odds ratio。用户/request 拥有 effect type；Agent 必须把 null `1` 显式
保留下来。Figure Intent 可把 supplied reference column 放在 `data.reference`，或把 supplied scalar 放在
`semantics.reference`；estimation family contract 声明 optional `reference`，adapter 验证 scalar，builder
绘制 reference line。deterministic visual runtime 不推断 odds-ratio null。本轮不增加 public field，也不
在多个 knowledge 文件重复该规则。
