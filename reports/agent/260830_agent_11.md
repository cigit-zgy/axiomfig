## 2. 发现并修复的真实问题

| 问题 | 证据 | 修复 |
|---|---|---|
| 双 cubic 路由出现明显弯折和局部束线 | 实际打开临时 canonical PNG 后拒绝该结果 | 改为一条平滑 cubic，并用 De Casteljau 分段保留可检查的 7 点路径表示 |
| 同一 source 的离开方向不足 | fan angle 最小间隔原门槛仅 1° | 按 target order 分配 source fan，回归门槛提高到 4° |
| route envelope 可能向 source label 一侧外扩 | 10-variable density case 出现 `Water chemistry -> Variable 10` 穿过 `Process state` 标签 | lane depth 受 source-to-rail depth 约束；source label bbox 完全放在 node 外侧 |
| 长矩阵标签和右侧 source 标签被裁切 | 正式字体顺序渲染后，`Chemical oxygen demand`、`Organic carbon`、`Spec04` 等不完整 | Mantel 标签改为 `clip_on=False`，让现有 panel solver 使用完整 renderer bbox，而不是裁切后的 bbox |
| Gallery 目标被 parity/atlas 稀释 | 37 对 Mantel parity 图和 5 张 review sheet 位于用户可见 Gallery | 删除 parity manifest、builder、专用测试和全部 atlas 产物；组合能力继续由 primitive tests 覆盖 |
| Evaluation 假定 Gallery 文件名等于 template ID | Mantel 展开 4 个正式案例后 coverage 误报 54/55 | Evaluation 从唯一 `GALLERY_SPECS` 投影每个模板的全部正式输出 |

没有通过放宽 footprint、collision、PDF、font 或 Gallery validation 获得通过结果。

## 3. 冻结后的 canonical grammar

```plain
Primary visual square
├── lower-left correlation matrix
│   ├── left labels
│   ├── bottom labels
│   ├── subtle cell scaffold
│   └── circle area proportional to abs(Pearson r)
├── diagonal interface
│   └── one TargetNode per variable
└── upper-right coupling triangle
    ├── separated SourceNode[]
    ├── target-ordered source fans
    ├── deterministic lanes
    └── smooth cubic routes

Outer ornament zone
├── Mantel p legend
├── Mantel |r| legend
└── Pearson colorbar Auxiliary Axes
```

变量名称只出现在 matrix 侧，不在对角接口重复。每条 link 从显式 SourceNode 开始，在对应
TargetNode 精确结束。canonical p-value 使用 AxiomOrange、AxiomGreen 与 faint AxiomGrey；Pearson
使用 AxiomRed → AxiomWhite → AxiomBlue；Mantel `abs(r)` 只控制共享 style contract 中的线宽。

## 8. 保留能力与限制

7 glyph、full/upper/lower/mixed、AOE/FPC/hclust、significance、CI、cluster outline、continuous
Mantel width 与 advanced 4-bin p-value 仍由 composition/engine tests 覆盖，但不再扩张正式 Gallery。

当前路由面向约 10–20 variables 的 manuscript-scale 图。任意高密度、跨越大量 target 的预计算
网络仍可能产生不可避免的 link crossings；AxiomFig 保证确定性、端点正确、triangle containment
与碰撞门槛，不承诺任意网络的无交叉平面嵌入。Mantel statistics 与 Pearson statistics 仍必须由
上游提供，绘图层不执行统计计算，也不声明与 R 输出 pixel parity。
