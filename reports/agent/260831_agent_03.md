# AxiomFig blind Agent scientific-routing benchmark

## 结论

**Verdict: PASS（benchmark round）。** 本轮从
`04f07129621c3d0f86c3a6c6627d30d8a5adb0d8` 开始，在 32 个 fresh、ephemeral、无宿主文件访问、
无网络访问的 Agent context 中执行了 blind scientific-routing sentinel benchmark。最终科学安全为
`31/32`，action accuracy 为 `30/32`，12 个 render case 的 template、family 和有效 Figure Intent
均为 `12/12`。8 个中文 case 的 action、render template 与科学安全均为 `100%`。

经本地完整验证与 GitHub Actions 验证的实现提交为
`f7d3f5c47425fee11ef84fa3d84f71cef689b6e1`。本报告由后续 report-only commit 收录；该 commit
不改变已验证实现，因此文件内不写入无法实现的自引用 SHA。

本轮没有修改 SKILL、科学知识、family contract、Figure Intent、runtime、template 或 Gallery。
没有运行 Stage B，因为 Stage A 没有导致 Skill/knowledge 修订；Stage C 为可选项，本轮在 32 个分层
sentinel 已提供明确诊断后停止，没有用重复运行训练仓库以追求分数。

| 项目 | 实际配置 |
|---|---|
| Agent | OpenAI Codex `gpt-5.6-sol` |
| Codex CLI | `0.149.1` |
| Reasoning | `high`；temperature 不可控制 |
| 日期 | 2026-08-31，Asia/Shanghai |
| Skill SHA-256 | `7969ae20c49fd0369456d7309579c29dfcc514d788953d3d80d3e4d6783102d5` |
| Corpus SHA-256 | `3e3346da0dd1bb4550a0cfc0f1c5dc0c515ee2a834f590bbe39b1c2d6f0b01c5` |
| Context policy | 每个 case 单独执行 `codex exec --ephemeral`；32 个 log 中有 32 个不同 session ID |
| User state | `--ignore-user-config --ignore-rules`，memory/apps/plugins 均禁用 |
| Filesystem | shell、unified exec、code-mode host、view-image 均禁用或 fail-closed |
| Network | browser、web/plugin surface 禁用；对抗探针确认 GitHub 不可达 |
| Agent input | 仅正常 Agent-facing Skill surface，以及一个去掉 ID/classes/expected 的 request/schema |

第一次预备运行曾使用较短的禁用列表。后置对抗探针发现该配置仍暴露 `web__run`，因此那次输出只作为
本地调试材料，**没有计入本文指标**。最终 Stage A 重新执行全部 32 个 context，并额外禁用了
plugins、remote plugin、tool suggestion、code-mode host、workspace dependency、goals、image 和 MCP
相关能力。对抗探针在明确要求读取 gold 与访问 GitHub 时返回 `false`；尝试 code mode 与 subagent
路径均 fail-closed。最终 32 个 stderr 中没有 Agent tool call。

`blind_agent.py` 技术上执行以下隔离：

1. 只复制 `SKILL.md`、Agent protocol、Figure Intent、routed template knowledge、Mantel reference、
   registry 和 family contracts；不复制 `tests/evaluation/`、reports、`.git` 或 symlink；
2. prompt 只包含 `request` 和 `available_data`，不包含 case ID、classes 或 expected fields；
3. 每个 case 启动一个新外部进程，结束后 orchestrator 才附加隐藏 case ID；
4. raw stdout/stderr 与 predictions 只保留在 ignored `tmp/agent-benchmark/`，没有提交模型输出。

为彻底关闭工具访问，本轮将完整但正常的 Agent-facing surface 一次性嵌入 prompt，而非让 Agent
按 progressive disclosure 动态读取。这不泄露 gold，但可能略高估真实按需路由下的表现；未来若有
严格目录级 file broker，可比较 eager surface 与 routed surface。

## Failure taxonomy and scientific safety

| Case | Prediction | Severity | Root cause | 处理 |
|---|---|---|---|---|
| `U07-paired-slope-plot` | `render` → `line.multi` | **B0** | **C** contract/scope ambiguity | 未改 gold/contract；单独列为科学安全失败 |
| `C20-causal-language-trap` | `unsupported`，而 gold 为 association-only clarification | **B1** | **A** model conservatism | 科学上安全但过度拒绝；现有 causality rule 已清楚，不重复文档 |

`U07` 是唯一 B0。Agent 把 long-form `subject, condition, value` 直接映射到 `line.multi` 的 numeric x、
2-D `series_values` 和 `series_labels`。该 Figure Intent 语法上有效，但数据形状不满足 adapter contract，
且当前 public surface 没有承诺 paired-design slope grammar。正确行为仍是 unsupported；若未来支持该图，
必须在独立 template/contract round 中决定，不应由 benchmark 临时扩面。

`C20` 正确拒绝用相关散点“证明因果”，但没有追问用户是否接受 association-only scatter，因此是错
action、不是科学安全事故。

## Quality audit of non-render actions

- Clarification：7 个正确 clarification 均只问科学上有材料差异的信息，包括 distribution versus
  summary、category/group mapping、trajectory、unit conversion、effect/null scale、uncertainty type 和
  importance definition；没有询问 marker、font、legend 或其他视觉细节。`C20` 是唯一 missed
  clarification。
- Require precomputed：8/8 均明确命名缺失结果，包括 PCA coordinates/loadings/variance、KM curve、
  Mantel matrix/links/r/p、PCoA/NMDS coordinates/metrics/stress、ROC points、volcano result roles 和
  clustering orders；没有指定分析软件。
- Unsupported：`U08` repeated-measures specialty、`U09` causal DAG 和 `U10` choropleth 正确拒绝；
  `U07` 错误进入 render，已作为 B0 单列。

## Architecture and token impact

- `tests/evaluation/blind_agent.py` 位于 evaluation layer，不进入 `src/axiomfig` 或 runtime dependency；
- runner 是 model/provider-independent external-command interface，不调用任何 proprietary SDK；
- 没有新增 `src/axiomfig/agent|llm|planner|reasoner`；
- Figure Intent 仍是唯一 LLM/runtime boundary；
- public templates 保持 55，registered non-public layouts 保持 4；
- `SKILL.md` 未改，normal discovery estimate 保持 `1743 tokens`；
- 没有实现 multi-panel user-data composition。

1. 在独立 scope 中决定 paired before-after/slope grammar 是否值得新增 template 或 typed adapter；在此
   之前保持 unsupported。
2. 后续模型/Skill 评估可检查 causality trap 中“拒绝因果 + 提议 association-only clarification”的

3. 如需要更窄的 progressive-disclosure benchmark，应提供严格目录级 read broker，使 Agent 可按需读取

   本轮未处理。
