# AxiomFig 架构收敛与视觉合同冻结报告

## 完成内容

本轮将 AxiomFig 收敛为三个唯一根配置源：`styles/style.yaml`、`styles/fonts.yaml` 和 `styles/colors.yaml`。Python 侧仅保留 YAML 加载、冻结、窄范围校验及 YAML 到 `rcParams`/token 的转换；模板压缩为 `curves.py`、`distributions.py`、`surfaces.py`、`panels.py` 四个图族模块，对外提供 line、scatter、bar、violin、heatmap、multi-panel 六个 builder。

已删除 16 个分散 `.mplstyle`、旧 style composition/override 层、9 个 resource template、旧动态 `styles.py`/`templates.py` 入口及 compose CLI。wheel 改为安装三份 YAML，不再包含旧 style/resource-template 层。

## YAML schema 与视觉 token

`style.yaml` 负责 geometry、物理字号、stroke、ticks、nice linear axis、legend、panel、layout、plot defaults 和 rendering；`fonts.yaml` 负责 mode、family、精确文件名、来源、许可证、版权和 redistribution 状态；`colors.yaml` 负责 canonical scientific palette。loader 检查顶层职责和关键物理数值的有限性、正值或非负约束，不引入通用配置框架。

冻结 token 如下：

- figure width：90、140、190 mm；默认 aspect 为 4:3；字号不随宽度缩放；
- `main_stroke = 0.8 pt`，`fill_edge = 0.6 pt`；
- open continuous axes：major `inout`、minor `in`；filled surface 和 colorbar：major/minor `out`；categorical tick marks 为 0；
- 实际 raster measurement 确认 `4 pt inout` major 的 inward projection 约为 `2 pt`，因此 minor length 冻结为 `1.236 pt = 0.618 × 2 pt`；
- nice linear axis 优先筛选 5–7 个 major tick，仅使用 `1/2/2.5/5 × 10^n`，minor step 为 `Δ/2`，limits 优先 major snap，明显空白时允许 half-step snap；
- single series 无 legend；multi-series legend 位于 axes 外 top-right、右边与 right spine 对齐、优先单行、仅真实 overflow 减少列数；
- panel label 为 `(a) (b) ...`、10 pt bold，以固定 point offset 位于 left/top spine 外侧；
- scatter 为 28 pt²、alpha 0.55、黑色 0.6 pt edge；bar 默认两位 value label；bar/violin 使用黑色 0.6 pt edge 且 categorical axis 无 tick marks。

## 字体与许可证

默认 sans/serif/mono/math 分别为 Latin Modern Sans、Latin Modern Roman、Maple Mono、Latin Modern Math。仓库未复制任何字体二进制；Latin Modern 使用 GUST Font License，Maple Mono 使用 SIL Open Font License 1.1，来源、license URL 和版权 attribution 均写入 `fonts.yaml`。Arial、Times New Roman、SimSun、Yu Gothic 仅作为 `bundled: false` 的 optional system font 记录。

## Gallery before/after

旧 Gallery 为根目录 10 组混合职责样例，包含 multilingual、serif 单例及旧 style-contract。新 Gallery 分为 `gallery/sans/` 和 `gallery/serif/`，两者各包含 `01_line`、`02_scatter`、`03_bar`、`04_violin`、`05_heatmap`、`06_multi_panel` 的 PDF/PNG，共 24 个正式 artifact，全部使用英文。

人工检查覆盖主线宽/填充边宽、open/filled tick 方向、minor/major 长度、categorical axis、scatter alpha/size、bar labels、panel labels、legend、普通 subplot 对称性、独立 heatmap colorbar 及 sans/serif 结构一致性。检查中发现并修复 single-column 标签裁切、standalone heatmap 左标签越界、violin 顶部余量和 colorbar tick 穿入色带问题；最终图未见这些缺陷。

## 验证结果

第一次完整测试为 `64 passed, 1 failed in 13.37 s`，墙钟 14.29 s。唯一失败来自仓库内陈旧 `build/` 被 setuptools 复用，导致 wheel 含已删除 `.mplstyle`；不是当前 package-data 配置错误。修复后 wheel 测试在排除 build/dist/tmp/cache/egg-info 的干净源码副本构建，并额外拒绝旧 Python/resource 入口。

## 尚未处理的边界

Chinese/Japanese font、mixed-script segmentation 和重型 multilingual probe 本轮明确暂停。TeX-native Matplotlib text pipeline 仍未实现；当前 Matplotlib 先把文本写入 intermediate PDF，Tectonic wrapper 不能在图内回溯展开 `\qty`、`\unit`、`\ce` 等宏。`references/latex-contract.md` 仅记录 TeX-native 文档可使用的准确通用语法，不宣称这些宏已支持 Matplotlib labels。

唯一 review 无 Critical；其有效 Important 已在一次 repair 中处理。review 建议把 panel label 的水平 offset 改为 0，但用户合同明确要求 `left spine - small fixed offset`，因此保留 `-2 pt` 并以 DPI-independent 测试固定。
